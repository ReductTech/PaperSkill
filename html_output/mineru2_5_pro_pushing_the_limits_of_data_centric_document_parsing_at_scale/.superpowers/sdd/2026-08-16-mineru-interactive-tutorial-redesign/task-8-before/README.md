# MinerU2.5-Pro 交互式网页教程

这是一个基于 PaperSkill 框架重构的 React + TypeScript 教程。它把静态论文组织成一条可探索的学习过程：

> 看见解析问题 → 发现数据瓶颈 → 挑选有效数据 → 判断样本难度 → 获得可信标注 → 分阶段训练 → 公平评测

页面以 MinerU2.5-Pro arXiv v2 为论文事实来源。所有自行设计的模型输出、公式错误和分块样例均标明“教学示意”；发布会材料只用于理解教学目标，不作为论文证据。

## 教程包含什么

- 一张可点击的复杂文档，让文字、公式、表格、版面与结构化输出联动。
- 一个基于 OmniDocBench 论文真实页面重构的 PDF 解析台：可在原始页面、结构化输出与困难版式之间切换，点击页眉页脚、多栏阅读顺序、旋转/合并表格等区域，查看它为什么难、模型需要恢复什么结构，以及对应到 MinerU2.5-Pro 的哪项机制。真实论文截图与教学叠层会明确区分。
- 首页按论文 Abstract 先讲清“共同失败现象 → 数据瓶颈诊断 → 三项核心工作 → 同架构增益”，再进入方法名和实验细节。
- 六步过程地图与 11 个主动实验采用逐章解锁：首章默认开放，正文只显示已解锁内容和紧邻的下一问题；每章末尾确认理解后继续，进度保存在本机并可重置。
- DDAS 覆盖选择、CMCV 先判断后揭示、Render-then-Verify 对比、三阶段训练、GRPO 组内排序、MGAM 分块合并与结果边界。
- 35 个可点击术语解释，以及可搜索、可分享的完整术语表。正文、实验引入、证据和关键公式在术语首次出现处直接提供解释入口。
- 所有动画都直接融入正文，用来建立直觉或反馈一次具体操作，不维护独立于教程的第二套叙事。
- 每一步先用“上一步得到 → 本节解决 → 交给下一步”建立因果桥；概念图首次进入视口会自动预演一次，用户点击后立即接管真实实验，最后用一句“本节回答”收束。
- 本地教学概念图融入首屏；各步骤分别使用文档缩略图、数据流、三模型分诊、渲染差异、训练轨道、候选重排和消融瀑布表达机制。
- 论文 Figure 2 与 Figure 3 已作为本地原图加入关键位置，并可按 DDAS、CMCV、Judge-and-Refine、页级采样和元素级采样等区域点击、局部放大或全屏核对。
- 最后一章提供可选的 Bilibili 学习任务、官方论文/代码和先修文献路线。每段视频遵循“观看前预测 → 带着三个问题观看 → 观看后自检”的闭环，并记录本地完成进度；只有主动点击播放时才加载外部播放器，并始终标明来源与证据边界。
- 所有交互都有即时动作反馈；在 `prefers-reduced-motion` 环境下会直接显示最终状态，不影响理解与操作。
- 过程步骤、实验状态和术语均支持 hash 深链；锁定章节的深链会定位到解锁提示，不会绕过学习顺序。

教程正文和全部实验可离线运行。只有用户主动播放 Bilibili 视频或打开论文、仓库和延伸资源时才会访问外部链接。

## 本地运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run build
node ../PaperSkill/paper-skill/scripts/validate-output.js .
```

生产构建输出位于 `dist/`。Vite 使用相对路径 `base: './'`，适合 GitHub Pages 子路径。

## 论文数字口径

- 约 60M 是页级候选；65.5M 是 Stage 1 跨任务训练样本。
- Stage 2 总计 3.9M，其中包含 192K 专家 Hard；Stage 3 使用 192K 高质量样本，GRPO 每个样本生成 16 个 rollout。
- Full 消融端点为 `92.98 → 94.29 → 95.25 → 95.69`；端点差为 2.71，分段增益因四舍五入合计为 2.72。
- Base 96.12 并非第一；296 页 Hard 测试集与训练完全隔离。
- arXiv v2 正文将 Hard 第二名写为 92.01、领先 2.07；同版附录 Table 8 仍列旧 PaddleOCR-VL 为 92.48、领先 1.60。教程保留并解释这一论文内部口径差异。

核心事实位于 `src/data/facts.ts`，六步内容位于 `src/data/tutorial.ts`，论文专属实验位于 `src/modules/`，统一术语表位于 `src/data/glossary.ts`。教学概念图只用于建立任务直觉；`public/images/paper-figure-2-data-engine.png` 与 `paper-figure-3-ddas.png` 来自 MinerU2.5-Pro arXiv v2，`real-case-*.png` 来自 OmniDocBench 论文的真实案例页，均在页面中标明来源与教学边界。
