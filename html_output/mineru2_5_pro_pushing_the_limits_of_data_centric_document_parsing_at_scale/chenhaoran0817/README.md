# MinerU2.5-Pro 交互式网页教程

这是一个基于 React、TypeScript 与 Vite 的 PaperSkill 教程。论文事实以 MinerU2.5-Pro arXiv v2 为准；教学重绘、合成输出、错误示例、路由和修复状态都与论文事实分开标注。

学习路径保留 6 个 chapter、11 个 active module 定义和全部显式 widget registry 映射，并以六种不同的主交互承载它们。每章遵循 PaperSkill 三段式结构：引入节（本节作用 + 生活类比自制小场景）→ 讲解节（1–2 个主交互模块）→ 总结节（恰好 3 条要点 + 一分钟自检）。

1. 数据瓶颈：在固定 1.2B 架构和相同预算下，用六个固定槽位比较“继续加入普通页”和“补公式、复杂表格、多栏长尾页”；三个长尾槽位是自制矢量教学示意页，不依赖位图加载。
2. DDAS：在六个真实候选缩略图上移动采样镜头，观察随机、聚类、难度感知三种结果，再进入文本、公式和表格的元素级热点。
3. CMCV：先看见明确的 `GT：不可用`（真实 PDF 输入为自制逐行扫描动画小图，无放大查看），再根据目标输出 C 与外部 A/B 的关系预测 Easy、Medium、Hard；结果会说明外部共识只是非 GT 的伪标签。
4. Render-then-Verify：在横向取证台中拖动滑杆，用扫显对比自制“原表重绘”与“断裂渲染”两张教学表格，看清合并单元格如何错位，再应用局部结构修复。
5. 训练与 GRPO：播放、暂停、拖动、逐段和重播训练时间轴；左侧自制模型数据流图随阶段演化（广覆盖流入 → Replay 回环 → rollout 分支与奖励回流），再按任务指标重排候选。
6. MGAM 与证据：章首先用"同一个答案、两种判分"的导入小实验看清分块粒度如何冤枉正确答案，再合并 held-out 预测块，观察匹配、评分与消融证据同步变化；输出规范差异用一行自制 Markdown 对照条展示，不再引用评测截图。

开头导入与章节跳转采用 PaperSkill 参考实现的模式：hero（出处芯片、中英文标题、核心问题/核心思路、关键词与作者元信息、方案对照）→ 论文问题速览 → 文档入门。导入两部分标注为"第 1 章 · 导入"：hero 的"开始探索"与 `#research-problem`、`#document-primer` 锚点都会直接揭示第一章。随后六章全部先隐藏，由"导入结束 · 开始探索"与每章末尾的"本章结束 · 继续探索 §N →"加载器逐章揭示，揭示只向前不回退。揭示是节奏而非锁定：顶部导航、可点击学习路线图与 `#step-N` 深链都可随时直达任意章节（一次揭示其全部前序章节），交互完成度只用于顶部 `0 / 6` 学习进度；页尾研究延伸区在第六章揭示后出现。hash 深链恢复各章的稳定交互状态。术语表、论文图查看器和本地学习进度继续可用。Bilibili 只出现在页尾延伸区，不参与章节访问、完成进度或论文证据；只有用户确认并主动播放时才创建第三方 iframe，关闭后立即卸载。

每章引入节改为上下两层：上方是精简后的"本节作用"桥卡，下方生活类比拉成通栏横带（左 244×130 自制场景、右文案）；第 1/3/5 章的类比带内置迷你交互——配菜预算可连续"再装一颗白菜"（样本数增加、长尾恒为 0）、对答案可拨"同一个老师"开关（两张答卷同时出错）、备考可点按三步节奏高亮。

桌面端以 1366×768 为基线，正文宽度上限约 1120px；六章按自然高度纵向连贯排列，章节内部不再出现横纵滚动区，内容直接完整展示（术语表、图查看器、延伸区等浮层除外）。真实论文媒体使用 `stage`、`thumbnail` 等有界展示语义；从局部裁图打开查看器时先保留当前裁图上下文，再允许切换到完整原图。Figure S3 使用一张完整横图和三个热点，避免把竖向裁图撑成大片留白。

## 本地媒体来源与边界

- `paper-figure-2-data-engine.png` 和 `paper-figure-3-ddas.png` 是 MinerU2.5-Pro arXiv v2 的 Figure 2/3 本地节选；当前仅 Figure 3 在第 2 章展示，Figure 2 节选保留在媒体库中未直接引用（第 5 章已改用自制演化示意图）。
- `real-case-output-comparison.png`、`real-case-layout-diversity.png`、`real-case-table-structure.png` 来自 OmniDocBench 的 Figure S3、S7、S10。
- `document-parsing-concept.png` 是教程自制教学图，不是论文原图。
- 第 1 章长尾页（公式 / 合并单元格表格 / 多栏）、第 4 章对比表格与第 5 章模型数据流图全部为 CSS/SVG 自制教学示意，不是论文或评测页面截图。
- 六章的生活类比小场景（配菜预算 / 挑西瓜 / 对答案 / 试菜 / 备考 / 拼图判分）与第 6 章判分导入实验同样是自制 SVG/DOM 教学示意，遵循一物一动一目标，不引用论文图片。

OmniDocBench 页面仅用于展示真实文档的输出规范、版式和表格结构难点，不能据此声称它们是 MinerU2.5-Pro 的训练样本、296 页 Hard 样本或性能证据。所有论文图片的发布许可状态仍须在发布前核验；页面保留来源直链和图片失败时的文字占位。

## 本地运行与验证

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

完整检查：

```powershell
npm test
npm run build
node ..\PaperSkill\paper-skill\scripts\validate-output.js .
```

生产构建输出到 `dist/`，Vite 使用相对路径 `base: './'`。

自动化测试覆盖自然文档流 CSS 合同、移动端字号与触控目标、渐进揭示与页尾门控、路线图跳转、章节三段式解剖（类比场景 / 三条要点 / 自检）、媒体裁图边界和交互状态恢复。已用 headless Edge（CDP 截图）在 1366×900 与 420×800 复核 hero、学习路线图、加载器、六章引入节/总结节与 06 判分导入实验的两种状态；发布前仍建议在 1920×1080 和 390×844 做一次人工视觉复核。

## 离线边界与非目标

断网后，六章正文交互、本地图片、术语与进度机制仍可使用；主动打开论文、代码仓库、延伸资源或 Bilibili 播放器需要网络，第三方 iframe 被阻止时可使用原站链接。

本项目没有四分钟展示版、极速演示版或独立视频模式，也不会保存视频完成状态。此次工作没有执行部署、Pull Request 或 Git 初始化。
