# HY-World 2.0 教程修改记录

本文档统一记录教程的人工优化版本。后续每次产生实质修改时，都应在顶部追加一个新版本，说明修改范围、依据、验证结果和待审查事项。

每个版本必须包含“模块变更明细”：逐项写出模块编号、模块名称、组件文件、新增或调整的具体内容，以及需要审查的状态变化。若没有修改运行模块，也必须明确写“无模块变更”，不能只写笼统的功能概述。

### 证据边界

- 模块不计算“创新分数”，也不根据节点数量判断哪个子系统更重要。
- 同一节点可以同时属于多个贡献类型；分类用于说明证据性质，不代表论文官方章节划分。
- 系统集成和运行时能力是论文整体贡献的一部分，但不能自动等同于新的网络结构或统一实验领先。
- 所有定量数字继续附带数据集、指标方向、分辨率、硬件或子协议边界。
