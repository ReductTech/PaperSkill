# RT-2：把网页知识迁移到机器人控制的视觉-语言-动作模型 交互式教程

基于论文 *RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control*，由 **paper-skill** 生成的完整 React + TypeScript + Vite 网页项目。

## 本地运行

```bash
npm install
npm run dev       # 开发预览 http://localhost:5173
npm run build     # 产出 dist/ 静态站点
npm run preview   # 预览构建结果
```

最终提交应保留整个项目目录，不要只复制 `index.html` 或 `dist/`。

## 内容结构

- 11 个幻灯片场景：封面 + 10 章（问题、语言、分词、训练、数据与对照、部署、评估协议、泛化、涌现、边界）。
- 20 个正文互动模块、22 个已注册组件；每章至少两个模块。
- 新增互动：
  - §5.1 数据来源：用大数字突出 13 台机器人、17 个月、同一间厨房，并展示 WebLI 规模和 PaLI-X / PaLM-E 的约 50% / 66% 机器人数据配比。
  - §5.2 基线阵容：RT-1、VC-1、R3M、MOO 改为大卡片，放大各自控制的变量和共同机器人数据口径。
  - §4.1 训练配方：三种配方并排强对比，展示动作、网页语义和同规模 5B 的 3%、28%、44% 读数。
  - §4.2 约束解码：大候选列表展示允许/屏蔽状态，约束关闭时 donkey 会成为最高候选。
  - §6.1 实时频率：解释 Hz 是完整闭环频率，并用云端五步流程展示 55B 1–3 Hz、5B 约 5 Hz 和 12B 未报告。
  - §10.2 边界：用证据矩阵筛选五种“新”，常驻图 9 解释红笔和香蕉的动力学失败。
  - §9.2 链式推理：改为图 7 任务切换和 Prompt/Plan/Action 顺序解锁，纠正跳步操作。
  - §7.1 评估协议：Seen / Unseen Objects / Backgrounds / Environments / Average 五档切换，先看 6k 总量与 200+ / 280+ 分母。
  - §7.2 A/B 轮转：用红/绿双模式对比“场景漂移”和“场景锁定”，并通过条件卡、模型上场状态和公式说明噪声如何被压下去。
  - §10.1 消融复盘：五根柱子支持「训练策略 / 模型规模 / 最差到最佳」对比视角，用差值括号解释 5B 与 55B、纯微调与共同微调的影响；页面直接嵌入图 6b 并配套读图讲解。
- 封面使用 14 个关键词组成词云（`RT-2`、`VLA`、`动作 token`、`256 bins`、`共同微调`、`约束解码`、`链式推理`、`泛化`、`涌现`、`55B`、`PaLM-E`、`Language-Table`、`6k 评估`、`PaLI-X`）。
- 封面左右对比改为同一套 Q 版水彩漫画：左侧只冒词句、机械臂不动；右侧八枚 token 串成抓取动作，机械臂把草莓放进碗里。
- 每章「本节作用」左侧不再复用回形针，改为 10 枚线性图标（放大镜、对话气泡、井号、滑杆、数据库、云、烧瓶、指南针、灯泡、盾牌）；章节小剧场改为单张技术路线画布，流程节点配有小图标、柔和圆角、细箭头和统一网格，顶部用「输入 / 变换 / 输出」三段式标签，不再叠加三块淡色背景分区。
- 3.1 改为四步引导式交互：先认识 7 个连续量（6 位姿 + 夹爪），再通过可调尺子理解每维 256 个 bin 的整数编号 0–255，随后逐维替换，最后补离散终止命令拼成 8 个 token；页面明确说明界面中的 256 是教学显示，不是论文原文给出的终止 token 编号。
- 全局 `Card` 增加标题色条与细分隔线，`Pill` / `Token` 增加内高光，`Arrow` 增加起点节点；所有模块内的方框与连线共用同一套描边和阴影。
- 全局视觉审计后，卡片阴影更柔和，滑块统一为蓝色渐变轨道与白色圆形手柄，按钮和槽位加入 hover、按压和键盘焦点；小剧场右侧元素全部收进白色内画板，避免越界。
- 章节小剧场使用 10 张独立透明背景 PNG（`public/images/character/chapter-1.png` 至 `chapter-10.png`），每章人物身份和道具不同；另有 4 张 `narrator-*.png` 供独立教学模块使用。所有图片均统一身体高度、脚底基线和四周留白，边缘使用平滑抗锯齿，不保留黑边、白边或孤立噪点。
- 人物安全区单独审计：所有含讲解员的 SVG 均检查人物实际不透明区域与框线、文字的交集，确保人物不接触框线或文字。

## 目录结构

| 路径 | 说明 | 是否生成器（Agent）修改 |
| ---- | ---- | ---- |
| `src/data/tutorial.ts` | 论文专属内容（章节、模块、公式、B 站、元信息） | ✅ 唯一数据文件 |
| `src/styles/paper.css` | 论文专属 `:root` 配色覆盖 | ✅ 仅此 CSS |
| `src/modules/*.tsx` + `registry.tsx` | 论文专属 Canvas 交互组件 | ✅ 在 registry 注册 |
| `public/images/*` | 论文原图（可选） | ✅ 仅放图 |
| `src/components/*` | 静态展示组件（Hero/Chapter/Module…） | ❌ 模板框架默认 |
| `src/lib/*` | 静态工具（canvasKit / B 站） | ❌ 模板框架默认 |
| `src/styles/{tokens,components}.css` | 静态设计令牌与组件样式 | ❌ 模板框架默认 |

## 配色语义（contract.md §5，保持稳定）

- `--blue` 指导/当前状态，`--green` 成功/本文方法，`--red` 失败/传统方法
- `--orange` 用户强调，`--purple` 辅助机制

切勿把 `--accent` 重新定义成别的语义角色。
