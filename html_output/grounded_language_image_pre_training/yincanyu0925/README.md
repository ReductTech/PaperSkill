# GLIP：让文字找到图像中的物体

《Grounded Language-Image Pre-training》（CVPR 2022）中文交互教程。制作：尹灿宇，AI辅助。

## 运行

需要 Node.js 20 或更新版本。执行 `npm ci`、`npm run dev`；生产构建为 `npm run build`。

## 阅读路线与交互

十章依次讲解任务、token监督、统一形式、点积与概率、双向融合、推理筛选、训练、结构、数据与适配、实验协议。十五个主动模块包括词标签选择、向量拖动与键盘调整、概率聚合对照、注意力分步计算、阈值实验、focal单变量更新、结构热点、数据消融与结果对比。

桌面端为本次验收范围。保留官方模板的固定宽度视口；不承诺手机适配。

## 事实与演示的界线

- 论文版本：CVF正式CVPR 2022 PDF，共11页，会议页码10965–10975。
- 所有展柜图、边框、小矩阵、向量与训练变量均为原创教学构造，未运行GLIP模型或训练权重，不构成实验复现。
- 实验数值来自论文表2–4；每组保留数据集、划分与指标。COCO跨域AP、LVIS AP/APr、Flickr30K R@1不能直接互比。
- COCO“零样本”指跨数据集迁移，不保证预训练没见过类别。普通GLIP-L微调的val/test-dev为60.8/61.0；61.5来自使用GoldG+及COCO的特殊test-dev配置。
- 点积不是概率；正文sigmoid focal分支对短语内token概率取平均。图中注意力例子省略可学习投影和后续编码层。
- 提示文字修改无需训练；学习提示P₀需要目标任务标注，不能称为零样本。
- 来源定位与边界表见 `EVIDENCE.md`。
