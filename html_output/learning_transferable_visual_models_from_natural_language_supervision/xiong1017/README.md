# CLIP：从图文配对到零样本分类

论文：Learning Transferable Visual Models From Natural Language Supervision（2021）。

原文：https://arxiv.org/abs/2103.00020

本教程对照 arXiv:2103.00020v1 制作，公开署名 xiong。包含10个章节、12个主动交互模块，覆盖自然语言监督、对比目标、相似度与温度、提示词、零样本、线性探针、双编码器、鲁棒性、数据重叠和偏见探针。

## 运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`。

## 证据与素材

章节和交互的反馈注明原论文节、图或表。二维特征、配对矩阵、鲁棒性示例和重叠加权演示均明确标注为教学示例，并非真实模型预测或训练日志。论文结果与教学数值分开展示，不同评价协议不混用。

页面图形由Canvas基本图元绘制；未打包原论文PDF、原文图片、外部字体或视频。延伸阅读链接到跟李沐学AI的CLIP论文精读（BV1SL4y1s7LQ），未复制视频内容。
