# CLIP · 交互式论文指南

面向初学者的 React + TypeScript + Vite 教程。采用顶部导航和章节目录，不设左侧目录，也不记录“学会”状态。

## 本地查看

在本目录运行：

~~~powershell
npm install
npm run dev -- --host 127.0.0.1
~~~

打开终端显示的网址，通常为 http://127.0.0.1:5173/。开发服务退出后，本地网址也会停止提供网页。已经打开旧页面时，可以按 Ctrl + F5 刷新。

生产构建与预览：

~~~powershell
npm run build
npm run preview
~~~

## 阅读与交互

- 10 章、11 个实验；正文以 18px、控件以 16px 为主，标题与操作文字加重。窄屏通过分行、单列及局部滚动保持可读性；KaTeX 字形与数学排版独立保留。
- 公式使用本地 KaTeX 排版，字体随构建打包，无外部 CDN。公式直接显示；悬停带点线的符号就近查看含义，点击可固定。触屏支持点击，键盘聚焦后按左右方向键逐个查看，Esc 关闭。
- 首页只保留首屏介绍与自动动画。封面每 4 秒换一个阶段，每完成三个阶段自动轮换示例；各章顶部每 3.4 秒切换本章相关环节，桌面画面宽度可达 480px。封面及顶部动画没有按钮、阶段点选或悬停暂停；后台标签页暂停，系统开启减少动态效果时展示静态结果。
- 普通章节目录、上一章与下一章，不设学习打卡、进度记录或隐藏正文的专注模式。
- 第三章分两步：先选择描述，即时认识原始配对与批内非配对；再查看同一批 3 对图文的 9 次比较。不要求做完配对题。矩阵、行列候选与就近读数同步更新；窄屏保留紧凑反馈卡。
- 向量可拖动或用键盘旋转，长度和方向独立控制。控件旁提供即时读数。
- 第五章支持单提示与多模板集成，始终至少保留一个模板。选择改变时，动画展示模板单位向量汇聚到真实均值，再沿同方向归一化；窄屏动画与模板按钮保持就近。
- 第六章的温度和候选操作联动“调整前／当前”概率分配图；总量、最高项和每行读数来自同一组 Softmax 结果。处理缺少正确类别、单候选、空候选及极端概率，移除按钮与即时概率位于同一行。
- 第七章分为“看损失”和“看分数更新”两个页签，切换时保留状态。每次真实更新只画出新增曲线段，显示概率分配和本步变化量；曲线紧接操作区，手机优先展示曲线。梯度明细按需展开，主要公式始终可见。
- 第2、8章提供醒目的“下一步 · 阶段名”、上一步与当前步骤；保留直接跳步。窗口足够高时操作栏在实验内部吸顶，矮屏恢复正常排版。
- 第八章采用输入、编码、投影、归一化、比较、输出六步工作区。矩阵格选择驱动向量平滑旋转、夹角扇区和余弦投影，窄屏矩阵读数旁也显示同步向量。批次／候选控制紧邻矩阵，数值与双向损失一致；说明可用 Esc 关闭并返回触发按钮。
- 实验协议选择与预算、分类器来源放在同一工作区。保留情境题、原论文结果与结论判断。
- 整体使用暖纸色、深墨蓝、靛蓝和哑金，统一选中态、悬停、聚焦和主要操作层级。

## 数据边界

机制实验使用明确标注的教学插画和模拟向量/分数，不调用真实 CLIP，也不把这些数字当作模型性能。第 10 章 Figure 7 结果来自原论文，并列出评估条件。

原论文：[Learning Transferable Visual Models From Natural Language Supervision](https://proceedings.mlr.press/v139/radford21a.html)

插画、示意图和动画由本教程的 SVG、HTML 与 CSS 绘制；未打包论文 PDF 或原论文图像。实验结果按原论文相应图表标注来源。延伸视频仅提供站外链接。数学字体随 KaTeX 依赖打包，其授权信息见 KaTeX 包的 LICENSE。

数学排版实现参考 [KaTeX API](https://katex.org/docs/api)，HTML 与 MathML 一起输出。

## 主要文件

- src/App.tsx：顶部导航、首页和章节。
- src/data/experience.ts：阅读路径、章节问题与操作引导。
- src/data/tutorial.ts：论文说明、分步公式、实验依据。
- src/components/MathText.tsx、mathMeanings.ts：共用数学排版与就近符号提示。
- src/components/ClipStoryline.tsx：章节顶部对应环节的循环动画。
- src/components/ClipCoverAnimation.tsx：封面三阶段图文匹配循环演示。
- src/components/Formula.tsx：常驻公式卡和符号解释。
- src/components/SceneArt.tsx：场景插画。
- src/modules/clip-*.tsx：11 个实验。
- src/styles/redesign.css、reading-polish.css、atelier.css、navigation-polish.css：全局阅读排版、字体层级、当前配色和响应式布局。
- src/modules/*-labs.css、matching.css、geometry-training.css、encoder-lab.css、encoder-flow.css、interaction-workbenches.css：实验样式。
