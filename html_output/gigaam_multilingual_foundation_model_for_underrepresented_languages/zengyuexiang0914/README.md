# GigaAM Multilingual 交互式论文实验室

围绕论文 **GigaAM Multilingual: Foundation Model for Underrepresented Languages** 制作的中文交互式学习网页。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 内容与素材

- 论文链接：https://arxiv.org/abs/2607.10371
- 页面图表根据论文表格中的数据重新编码绘制。
- 项目未复制论文插图，也不包含论文 PDF、账号信息、密钥或本地绝对路径。

主要交互包括语言观察器、方法流程、语言数据来源比较、E0–E3 采样实验、模型结果对比和理解测验。
