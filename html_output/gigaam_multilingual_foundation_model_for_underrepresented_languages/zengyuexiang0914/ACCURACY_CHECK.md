## 提交前建议人工检查

1. 逐项点击语言、方法步骤、E0–E3、结果语言和测验选项，确认反馈正确。
2. 用桌面浏览器和手机各检查一次，确认无横向溢出、遮挡或字体缺失。
3. 重点复核表 1、表 3、表 5、表 6；WER 越低越好。
4. 如果提交到 PaperSkill 公共仓库，按其要求使用 `html_output/<paper-name>/<姓名拼音+日期>/` 目录，并在创建公开 PR 前完成人工确认。
