# 桃源 · 提示训练师

围绕《The Power of Scale for Parameter-Efficient Prompt Tuning》（arXiv:2104.08691v2）的十章中文交互故事。

你是 **Robot Prompt Trainer**。机器人已有通用语言能力；核心权重只读。通过任务签、连续提示、冻结训练、尺度与设计消融、跨域实验和同任务提示投票，理解轻量任务适配。

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

打开 http://127.0.0.1:5173/ 。构建：`npm run build`；构建后预览：`npm run preview`。

## 学习方式

底部按钮逐章进入，也可使用顶部章节目录。章节状态在本次页面会话中保留；刷新会重置。手机和桌面均可操作，拖动实验另有等效按钮。

## 科学边界

- 这是教学交互，不下载 T5，不调用在线模型。机器人对话与投票为明确标注的脚本示例。
- 训练章节运行可计算的一维二分类 toy，只更新提示参数。它不是 T5 训练、论文收敛曲线或真实任务分数。
- Figure 1 / Figure 3 的尺度、长度与初始化交互展示定性结论，不伪造原图点值。
- Table 1 / Table 2 的跨域实验保留精确均值、标准差、指标方向与反例；Table 3 展示精确开发集集成结果。
- LM adaptation 是上游一次性底座训练，发生在冻结交付前；下游 Prompt Tuning 只更新提示。本文结论不能推广为所有任务都无需完整微调。
- 节省任务参数存储不等于省去底座前后向计算；集成仍需多个条件实例。

## 依据

[原论文 v2](https://arxiv.org/abs/2104.08691v2)，Brian Lester、Rami Al-Rfou、Noah Constant，Google Research，2021。正文每个实验附论文章节、图表和评价协议。

应用只依赖 React / React DOM；构建工具为 Vite / TypeScript。无远程字体、CDN 或数学渲染服务。延伸视频可选访问 Bilibili；元数据失败时仍保留视频链接。

## 思考与场景

每章提供一道人物视角的三选项问题，选择后显示原因与概念总结，可随时换选项。概念图由章节控件驱动：机器人气泡回应任务切换，办公场景表现多任务成本，后续通过向量、梯度路径、损失函数、尺度趋势、消融、跨域误差条与投票逐步理解论文。

## 训练档案复盘

每章末尾的浓缩笔记可点击“记录至档案”。第十章之后进入复盘：依据引导提示将打乱的十张卡片放入论证流程，可点击放置、取回重排或桌面拖放。检查排列会提供反馈，完整正确排列后展示最终总结。归档与排列在当前浏览器、当前网站地址的本地存储中保存，刷新后可继续。

## 按钮式教学转场

十章每次只显示一个内容场景。底部引导按钮依次进入开场、实验、公式（若有）、思考题与训练笔记；返回按钮先回到本章上一部分。各实验和答题状态在本次浏览期间保留，归档与复盘排列继续保存在本地。标题采用系统楷体/仿宋回退，并用柔和线描图标标识场景层级。
