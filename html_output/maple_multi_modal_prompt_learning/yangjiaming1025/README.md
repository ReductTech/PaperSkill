# MaPLe：图文协同的提示学习

面向初读者的简体中文交互教程。基于 CVPR 2023 论文 *MaPLe: Multi-modal Prompt Learning*，使用 React、TypeScript、Vite。

## 运行

在本文件所在目录打开终端：

```powershell
npm install
npm run dev -- --host localhost
```

打开终端显示的本地地址。不要直接双击 index.html；这是需要 Vite 编译的 React 项目。

```powershell
npm run build
npm run preview -- --host localhost
```

构建输出是 dist/，可以发布到静态网站托管服务。项目使用相对资源路径。仅本地预览不会发布网页。

## 学习顺序

1. 四种方法的提示位置：CLIP、CoOp、CoCoOp、MaPLe。
2. 图像与类别特征如何比较：二维点积实验。
3. 改变图片或类别，检查训练后保持不变的提示。
4. 拖动文字提示，比较独立双支与耦合双支。
5. 走过十二层：替换提示槽位，保留普通 token，超过 J 后继续传播。
6. 区分新类别、跨数据集、域变化三种评测。
7. 冻结运算中的梯度，及 MaPLe 的双路径反传。
8. 五步拼回完整网络，区分提示映射与最终特征投影。
9. 深度/长度结构实验与参数成本。
10. 真实结果表、HM 数学练习、消融与泛化边界。

共 10 章、11 个主交互模块、10 个图鉴类比动画与封面对照。每章含操作反馈与三条要点。

## 操作

- 顶部 0–10 数字按钮切换封面与章节；页尾按钮可按顺序阅读。数字按钮悬停显示章节名称，带点表示已访问。
- 封面可切换 CoOp / MaPLe，并通过“换一组提示”观察文字提示与视觉提示的依赖。
- 第 4 章可以拖动绿点，也可使用四向按钮或聚焦图框后按方向键。
- 滑块支持键盘；操作控件时方向键不会意外翻章。
- 鼠标悬停在公式符号上即可查看解释；键盘 Tab 聚焦、触屏点按同样可用，Escape 可收起说明。
- 第 5、6、7、8 章支持逐步查看、自动播放和暂停；手动选步会停止自动播放，离开可见区域也会暂停。
- 第 5 章可直接选择 12 个编码层，再分四步观察提示保留、替换与编码。
- 第 1 章增加换图对照；第 2 章可直接点选候选分数卡；第 9 章可点击图中层位置调节深度；第 10 章增加均衡与偏斜分数快捷对照。
- 大图可点击“放大图示”，横向滚动查看细节，再点击“收起图示”。
- 手机端同样使用顶部数字导航。放大窗口可横向查看全图，按 Escape 或点击“收起图示”退出。
- 系统启用“减少动态效果”时，循环场景保持静止；画布移出视口时停止动画。

## 事实与教学示例

二维特征、二维到三维映射、标量梯度与固定平均值的 HM 练习都是明确标注的教学示例，不是 CLIP 实测特征或论文性能。深度/长度滑块只计算结构，不预测准确率。

真实结果来自论文 Table 1、3、4、5、6、7；显示对应实验条件与限制。11 数据集汇总 HM 按汇总 Base/New 计算。MaPLe 的平均 HM 最好，不表示每个数据集、每项指标都最好。
