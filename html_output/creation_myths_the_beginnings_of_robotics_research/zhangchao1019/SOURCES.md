# 原文与教学边界

Matthew T. Mason. *Creation Myths: The Beginnings of Robotics Research*. IEEE Robotics & Automation Magazine, June 2012, pp. 72–77. [DOI: 10.1109/MRA.2012.2191437](https://doi.org/10.1109/MRA.2012.2191437)。内容依据用户提供的本地 PDF，未将原文 PDF 或受限图片复制到项目。

| 网页场景 | 印刷页码 | 原文依据与边界 |
| --- | --- | --- |
| 研究边界 | 72 | Origin of Robotics Research：持续的共同研究活动，区别于机器、哲学和文学前史。 |
| 四种起源 | 73–74 | Myth #1 / More Creation Myths：遥操作、工业、机械科学、计算机科学的不同文化视角；约数不是精确断代。 |
| 几何规划 | 73、77 | 正文追溯构形空间工作到 1977；参考文献 [16] 是 1978 技术报告，[17] 是 1979 期刊论文。圆盘障碍膨胀仅作简化教学。 |
| 范式革命 | 74–75 | Mason 将 Thrun 等的中期年代向后推五年，以约十年节律呈现；行为和统计是革命，未覆盖所有机器人分支，2010 年事件未确定。 |
| 曲柄与不确定性 | 75 | Goertz 1952 年已讨论让曲柄决定轨迹。网页演示几何冲突，没有模拟接触力、动力学或控制稳定性。 |
| 三种定义 | 76 | Definitions 1–3：与机器人协同设计、为任务工程化、机器人可利用的规律；针对给定任务判断。 |
| 连续性 | 76 | Definition 4：结构化程度具有连续性。信息论尺度只是可能方向，没有通用计算公式。 |
| 工厂权衡 | 76 | 成本、产品变更、感知与预先消除不确定性的权衡；网页函数及系数为教学设定。 |
| 厨房适配 | 76 | 平地、标准台面及器物可供性。把手与夹爪尺寸非原文数据，也不代表完整抓取分析。 |
| 长期进度 | 76–77 | The Future：缺乏衡量长期目标进展的有效尺度。技能格子不是统计或能力排行榜。 |
