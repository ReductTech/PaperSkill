# DETR：把物体逐个找出来

《End-to-End Object Detection with Transformers》（ECCV 2020）的中文交互导读。沿着“两个人、一辆车”的同一张示意照片，学习目标检测、特征与位置、集合预测、目标查询、最优配对和训练损失。

10章、13个主动交互模块。先看例子和操作，再给概念命名，最后走一遍计算。讲解范围为原始DETR。

## 本地运行

```sh
npm ci
npm run dev
```

`npm run build` 完成TypeScript检查和静态构建。

## 主要交互

- 切换分类与检测，逐条对应物体记录；对照重复预测与一一监督。
- 选择图片格子，查看卷积特征、展平位置与空间位置编码的关系。
- 交换预测的顺序，比较固定顺序评分与最优一一配对。
- 拖动方框，实时计算归一化坐标、L1、IoU、GIoU和框损失；方向键也可操作。
- 切换查询向量，实际计算点积、softmax比例和加权读取结果。
- 逐步读取并行预测，调整展示阈值，观察记录与方框同步变化。
- 遍历两个目标与三个预测的六种配法，计算类别和方框共同构成的匹配代价。
- 逐步更新一个类别分数，查看概率、梯度和分类损失。
- 点选网络部件，检查张量形状；切换训练模式，查看辅助监督与匹配位置。
- 切换真实照片的原图、低清和遮挡版本，查看实际模型预测。
- 比较论文的总体、小物体和大物体AP，另看300轮协议下的消融成绩。

## 实验如何运行

页面第9章使用保存的实际推理数据。实验脚本为 `experiments/run_inference.py`，完整结果为 `experiments/results.json`，包含九次推理各自100个位置的原始logits和框、输入图片SHA-256、阈值、预处理、环境版本及单次前向耗时。结果还记录官方代码提交和权重指纹。

```sh
python -m pip install -r experiments/requirements.txt
python experiments/run_inference.py
```

首次运行会下载官方源码和预训练权重。脚本使用固定提交 `29901c51d7fe8712168b8d0d64351170bc0f83e0` 的官方DETR-R50，在CPU评估模式下推理。三张照片各测试原图、低清和中心遮挡，共9次；低清处理先把短边缩到48像素再还原，遮挡用固定灰色矩形覆盖约19%的图像面积。进入模型前，短边缩放到800、长边限制为1333，并使用相同归一化。

展示规则是“最高非空类别概率至少0.7”，不使用NMS。每个目标的最高类别概率取自100个预测位置。页面显示保存的单次观测，耗时只覆盖模型前向计算；复跑耗时会随机器和负载变化。未重新训练DETR，也未用三张图片估计完整数据集的AP。

真实输出中的一个例子：咖啡杯原图的杯子最高概率约0.9975，遮挡后约0.0012，展示记录变为碗、餐桌和勺子。宇航员和猫在这次中心遮挡下仍达到0.7阈值。原图中的额外预测也完整保留，便于讨论误检和类别判断。

脚本重新运行会更新实验记录和图片；页面内嵌的是本次保存的结果。如需将新一轮结果更新到页面，请同步更新第9章的数据。

## 教学数值与论文成绩

前8章的街景图为自行绘制的教学示意。二维特征、四个预测位置和单个类别分数更新均为标明来源的教学算例。框几何和softmax在浏览器内实际计算；第7章的单变量更新帮助理解梯度。

第10章的正式成绩来自原论文：表1使用COCO 2017验证集，DETR为500轮训练，Faster R-CNN-FPN+为加强配置、约109轮；两者总体AP均42.0，小物体AP分别20.5和26.6，大物体AP分别61.1和53.4。表3、表4的消融使用300轮训练，报告最后10轮验证成绩的中位数，完整设置为40.6。训练和汇总协议在页面相应位置说明。
