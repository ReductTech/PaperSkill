# 潜入 Claude Code 源码泄露 · 交互式教程

基于 *Diving into Claude Code's Source Code Leak* 的中文交互式讲解，13 页幻灯片、5 个章节。
教程用一家"印刷厂"的日常动作（清点出货清单、值班、卡片柜、铅版、封条）解释泄漏源码里
五个可分离的设计决策，全部用浏览器内的确定性规则演示。

## 来源

  记录了对应原文章节、教学模型的状态，以及哪些结论属于作者判断。

## 教学主张

原文读起来像一份"内幕清单"，本教程把它压成一条可讨论的线索：

> 泄漏真正暴露的不是代码，而是**取舍**——五条关键决策都被放到了更难改、也更难绕过的层。

- 主动性：判定与执行分离（KAIROS 的心跳与门槛）
- 反蒸馏：防御点前移到数据采集端（`fake_tools` 与摘要回传）
- 记忆：索引常驻，主题按需，对话记录只被检索
- 缓存：稳定前缀与动态后缀切开（`SYSTEM_PROMPT_DYNAMIC_BOUNDARY`）
- 安全：策略单向门与原生层签名（`undercover`、`cch`）

## 演示修订

按 [新芽幻灯片指南](https://grokcv.site/sprouts/guide/) 与
[张雨函的分享建议](https://grokcv.site/sprouts/yuhan/) 调整：

- **一页一观点**：13 页全部使用结论式标题，页面副标题是一个问题；操作步骤、来源定位与
  类比边界放进讲稿，主视图不出现整段文字。
- **字号与栅格**：正文 30px、局部标题 36px、焦点数字 46px（1600×900 固定画布，约合
  22.5pt；全屏播放时按视口整体放大）。字号只有三档，标题、页脚、章节标记位置全篇统一。
- **配色克制**：主色蓝灰 + 纸张米色，语义色只用三种——蓝=当前/指导、绿=通过、红=风险，
  橙色只标"用户可调的强调量"；没有渐变背景和高饱和荧光色。
- **开篇信息完整**：作者、载体、日期、类型、互动量、机构缺失都写在第二页，并明确区分
  文章报告、作者推断和本教程的教学模型三层边界。
- **公式配解释**：缓存页给出 `C轮 ≈ 0.1 × T缓存 + T重算`，三个符号可悬停/聚焦查看中文含义，
  旁边直接给出当前的命中率与每轮成本。
- **图表先结论**：每张表和图都配一句"测什么"或"这一格检验什么"，实验矩阵的四个格子各自
  标出指标与风险；证据页用三档强度替代模糊的"据说"。
- **动画节制**：只有封面有两段同步演示，其余交互是点击/拖动后立即反馈，没有旋转、飞入
  或循环动画。
- **批判性收尾**：结尾之前固定有"证据强度"和"我的思考"两页，明确写出未复现的部分、
  三条共同局限，以及一个 2×2 后续实验设计（没有填写任何虚构结果）。
- **时间分配**：建议 14–16 分钟；讲稿逐页给出建议时长、操作顺序、停顿点和过渡句。

## 本轮验证与人工检查

- `node syntax-check.js --require-parser`、`validate-output.js`、`npm run build` 均通过。
- 用无头浏览器逐页渲染 13 页并运行几何审计：页面级无滚动、无越界；剩余提示均为行高
  取整造成的 4–5px 误差。
- 人工检查建议：桌面 1600×900、笔记本 1366×768、手机竖屏与横屏各看一遍；操作全部
  8 个交互（封面播放、发布清单、心跳门槛、假工具、记忆分层、缓存边界、单向门、账本、
  实验矩阵），检查标题、反馈与图表没有遮挡或裁切。
