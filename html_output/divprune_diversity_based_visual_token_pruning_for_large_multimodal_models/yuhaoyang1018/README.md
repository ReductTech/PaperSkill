# DivPrune 交互式中文精读

论文：*DivPrune: Diversity-based Visual Token Pruning for Large Multimodal Models*（Saeed Ranjbar Alvar, Gursimran Singh, Mohammad Akbari, Yong Zhang · Huawei Technologies Canada · **CVPR 2025**，第 9392–9401 页）。

本项目基于 [PaperSkill](https://github.com/ReductTech/PaperSkill) 的 React + TypeScript + Vite 模板（`paper-skill/assets/react-template`，模板来自 commit `54682a7`）制作，内容为简体中文。完整工程是本目录本身；`dist/` 只是构建产物。

## 运行

需要 Node.js 20 及以上。

```bash
npm ci            # 按 package-lock.json 安装依赖
npm run dev       # 本地预览 http://localhost:5173
npm run build     # tsc 类型检查 + vite 构建，产出 dist/
npm run preview   # 预览构建结果
```

PaperSkill 校验（在 PaperSkill 仓库根目录执行，路径换成本目录）：

```bash
node paper-skill/scripts/syntax-check.js <本目录> --require-parser
node paper-skill/scripts/validate-output.js <本目录>
```

调试用参数：`?motion=reduce` 会强制进入“减少动态效果”模式（与系统设置 `prefers-reduced-motion: reduce` 走同一条代码路径），用于在无法修改系统设置的环境中复核。

## 与官方模板的差异

为满足“单页长滚动 + 手机端可用”的要求，以下改动超出了模板约定（模板约定只改 `tutorial.ts`、`paper.css`、`modules/*`）：

1. **`index.html`**：视口由模板的固定 `width=1600` 改为 `width=device-width, initial-scale=1, viewport-fit=cover`，并补充 `theme-color`、`color-scheme`、`description`。
2. **`src/App.tsx`**：由“左侧目录 + 一章一屏 + 底部上一章/下一章”的幻灯片布局改为单页长滚动；只保留顶部阅读进度条和右下角悬浮章节导航；增加滚动入场与减少动态效果的处理。
3. **`src/main.tsx`**：不再引入 `src/styles/components.css`（幻灯片布局样式）；该文件本身保留未改动。`tokens.css` 仍然引入。
4. **`src/types.ts`**：只做了**追加可选字段**（章节导语、正文、多公式 `formulas`、深读 `deepDives`、易错点、证据表、术语表、结论分级、Hero 扩展等），模板原有字段全部保留。
5. **`src/modules/registry.tsx`**：注册了本工程的组件；模板自带的 `example-slider` 保留注册。
6. **新增目录 / 文件**：`src/components/dp/`、`src/ui/`、`src/lib/hooks.ts`、`src/lib/maxmin.ts`、`src/lib/flops.ts`、`src/lib/palette.ts`。模板的 `src/components/*`、`src/lib/canvasKit.ts`、`src/lib/useBiliVideos.ts`、`tokens.css`、`components.css` 均未修改。
7. **视频推荐**：模板的 B 站组件（`BiliVideos.tsx`、`useBiliVideos.ts`）保留在工程中，但页面不渲染；`tutorial.ts` 中没有 `bilibili` 字段。
8. **配色**：页面使用冷白“晨光实验室”主题（刻意与同系列 FastV 版的深色电影风格区分；珊瑚红 = DivPrune / 已选，钴蓝 = 候选 / 距离 / 当前状态，琥珀金 = 重要性方法 FastV），与模板 `contract.md` §5 的红/绿语义不同；页面内部语义保持一致，图例随组件给出。
9. **运行时依赖**仍只有 `react`、`react-dom`；无 CDN、外部字体、密钥或环境变量。

## 内容口径

- **编号与数字**一律以 CVPR 2025 正式版（CVF Open Access）及其补充材料为准；补充材料的图表注明 `supp`。证据芯片中的页码指向正式版 PDF。
- **代码引用**固定到 [vbdi/divprune](https://github.com/vbdi/divprune) 的 commit `799e2d950aa01ba7860907f5a6d86061f885dca6`（核心文件最后修改于 `689ab4d`）。
- 页面用四种标记区分内容来源：
  - **论文实测**：直接取自论文表格 / 图 / 正文；
  - **代码事实**：直接取自官方代码（附行号链接）；
  - **公式外推**：按论文公式或官方代码计算得到、论文未报告的数字（如 C(576, 56)、Table 3 反推的保留数 39/21/2，以及仅限独立二元正确率假设的标准误教学示例）；
  - **教学示意**：为讲解绘制或生成的数据（二维点云、示意图块场景、5 层小模型），不是真实数据。
- 复算结果：按 `tflops.py`（二次项为 +）复算 16 个可核对配置，15 个与论文一致；视频模型 FastV 的 14.20% 无法复现，页面标注“与本页复算不一致，原因未知”。论文 Eq. (5) 印刷的 −2μ²d 无法复现表格，页面将其作为排版错误指出。
- 页面中写明“本页推测 / 推断”的内容是解读，不代表论文结论；结论按“已证明 / 有解释但未证实 / 仍然未知”分级。
- 页面不包含任何视频平台推荐。

## 版本记录

- **v1**：首次交付。
- **v2（呈现改版）**：参照同系列 FastV 版的节奏重排版式——每章改为“片头卡 + 开场卡（本节作用 + 类比画布）”，正文压缩约三分之一，长段落移入默认折叠的“精读”（关键数字常驻）；新增醒目的“核对”条承载论文与表格 / 代码不一致之处；公式改为“公式 + 一句话串讲 + 符号芯片”；要点与误区合并；10 个类比画面改为不同的实验台器物（不再重复同一个人物）；Hero 增加新旧方法对决面板；指标卡与画布加大、加纸感底纹。论文数字、证据芯片、代码对照与结论分级内容不变。

- **v3（电影感改版，只改呈现）**：参照 FastV 版改为深色电影感主题——全屏光束 / 微尘背景、胶片颗粒、开场遮幅与聚光、标题对焦 + 流光、玻璃章节面板与流光顶边、发光的模块 / 按钮 / 滑块 / 证据芯片。交互改为有过程的动画：所有画布切换时旧画面淡出、新画面透出（不再瞬间跳变）；2.1、5.1、7.1、8.1、1.1 改为逐帧舞台（被选中的点放大发光、连线“长出来”、D 的柱子依次升起、被选点发出涟漪、图块随光波切换、柱子逐层升降）；反馈文字变化时轻微淡入。修复：容器宽度尚未就绪时画布算出负半径会抛错并导致整页卸载（本地开发环境中实测出现）；手机端多行章节标题只显示第一行；每个交互组件加了错误边界。论文数字、证据芯片、代码对照与结论分级内容不变。
- **v4（换成亮色主题，只改呈现）**：为避免与 FastV 版同质化，背景与氛围从深色电影幕布改为冷白“晨光实验室”——冷白底、漂移的珊瑚 / 蓝紫 / 薄荷极光、呼应 Max-Min 的星座背景、毛玻璃白面板、珊瑚 → 蓝紫 → 钴蓝渐变标题与章节号、柔和的彩色阴影。v3 的全部交互动画（画布淡入淡出、逐帧舞台、反馈淡入）与修复保留。
- **v5（按浏览器评审修订）**：① 10.1 去掉单模型 ±1.96 SE 误差带及据此做的“无法区分 / 大概率不是噪声”判断（F1 不是逐题准确率，单模型区间也不能比较两个模型），只报告表中差值；同步修改核对条、深读、结论分级与术语表，标准误公式改为明确限定的教学示例。② 5.1 修复“取 argmax”一步最大柱与连线被隐藏的问题，柱顶标数值、点旁标编号，结束语区分两个阶段 D 的定义、只对第二阶段陈述“不增”。③ 9.1 计算器：切到自定义时完整复制模型、数据集范围、K 与保留规则（新增“按比例 / 固定个数”），切换模型时 K 同步约束，新增“回到起点 / 恢复论文默认”。④ 手机端 5.1 改为“画布 → 本步解释 → 按钮 → 伪代码（默认只显示本步行）”，10.1 方法名移到条形上方。⑤ 2.1 新增三个场景（高分集中 / 高分分散 / 无关离群点）与“平均相关性（场景设定）”一列。⑥ 10.2 降低因果措辞。⑦ 背景动画实时响应“减少动态效果”。⑧ 封面增加三条阅读路线。
- **v6（按线上复评修订）**：① 第 2 章要点改为“高分集中时可能扎堆”“覆盖与相关性要权衡”，与新增的反例场景一致。② 手机端收窄章节 / 模块内边距、画布向两侧外扩：390 宽下画布约 330px，320 宽下约 260px。③ 5.1 新增“先猜下一点”挑战模式：计算步先隐藏 D 柱，读者点出（或从列表选择）预测的点后才揭晓；猜错时用两点的 D 值解释原因，结束时统计猜对轮数；直接演示模式与自动播放保留。
- **v7（小屏精修）**：5.1 挑战模式答错时先给“数值比较 + 一句原因”，完整 argmax 串讲收进可展开的“完整解释”（320 宽下反馈高度约 217px → 121px）；画布内 D 标签缩短为“到最近邻的距离 / 到已选集合的最近距离”，“柱高按本轮最大值缩放”移到图下可换行的说明。
