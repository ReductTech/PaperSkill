# OVOD-Agent 中文交互式导读

参与者：刘通（wudiergouzi）。

## 使用

运行 `npm install`、`npm run dev`。生产构建使用 `npm run build`。

## 来源

论文：https://arxiv.org/abs/2511.21064v2 ，CVPR 2026。作者：Chujie Wang、Jianyu Lu、Zhiyuan Luo、Xi Chen、Chu He。

全部插图为原创 SVG 失物招领示意，无外部角色或图片。10 个问题覆盖动作、UCB、Markov 更新、奖励方向、RM 学习、部署、证据与边界。交互中的概率、损失示例已标注为教学值；只有结果页引用原文表 2 数据。

## 内容审查

摘要八状态空间与正文七原始动作分开解释；1−IoU 的不确定性方向与不确定性下降反馈分开；表 2 与消融表不拼接。未运行原模型训练，未宣称复现实验。
