# VibeThinker-3B 中文交互式论文教程

人工智能实践课第一次作业。制作：吴宇石（wuyushi / yfrcg）。
原文：[arXiv:2606.16140v1](https://arxiv.org/html/2606.16140v1)。

## 当前版本

在 Paper Skill 初始项目基础上，按参与者要求重新导演内容与设计。采用纸色背景、深色正文、赭色重点和杂志式排版，组织为研究问题、数据与解法谱、强化学习、推理时核验、训练全貌、实验与审读六部分。关键讲解整合进六节因果正文，原文索引与奖励公式可按需展开。

八个主要实验支持样本筛选预测、多路径切换、逐次采样对错、奖励长度与正确性调整、关键主张判定、训练阶段探索、自由编辑JSON答案、基准过滤与CLR对比。另有可选点参数图、上下文窗口滑块与评测协议切换。教学构造与论文报告数据分别说明，未调用真实模型。

推荐从“推理时核验”开始：检查平方引入的增根，改变自验证判定，看少数正确答案反超多数错答；再故意让验证器全部误判，观察为何自验证仍会失败。

制作时特别保留三点审读判断：本报告未提供各训练组件逐项量化消融；未提供完整训练算力、成本与时延；CLR使用额外推理预算。这些是对报告证据范围的审读，不能冒充新增实验结果。

## 因果讲解补充

六部分各增加三段连续精读，按问题、机制、剩余问题组织。新增可验证反馈与SFT/RL基础解释、两阶段课程动机、相对优势简化算例、MGPO筛选与加权区别、上下文与简洁性关系、CLR五步增根推导、NLL学习潜力算例、自蒸馏与推理时选择区别、评测分母及消融设计。每节有解释反馈的理解题和通往下一节的因果衔接。教学算例和建议实验均明确区别于论文报告。

## 交互图解

每节正文前增加原创SVG图解，共六幅、20个可切换状态：全文路线、解法分叉、能力边界、CLR票权流向、自蒸馏材料汇流、数学与知识成绩。路径流动与阶段高亮辅助阅读，支持减少动态效果的系统偏好；手机可在图内横向查看。所有示意图说明其教学性质，结果图使用论文原始分数。

## 内容精简

合并旧精读与因果正文中的重复讲解，移除重复操作提示、首页路线列表和重复局限总结；保留六幅图解、八个实验、五步推导与六道理解题。公式保留在相关方法旁，完整奖励公式与原文索引按需展开。

## 源码

- `src/VisualAtlas.tsx`：六幅SVG交互图解。
- `src/Narrative.tsx`：连续因果讲解、五步推导、章节理解题与承接。
- `src/Experience.tsx`：当前页面结构与交互实验。
- `src/styles/experience.css`：当前响应式视觉样式。
- `src/data/tutorial.ts`：论文精读内容与来源。
- `src/modules/long-short.tsx`：复用奖励再分配纯函数。
- `src/main.tsx`：新版入口。

旧模板组件与模块保留供追溯，当前入口不渲染旧版页面。SVG、HTML和CSS图形均为代码绘制，无外部字体、图片、CDN或模型依赖。项目框架来自[ReductTech/PaperSkill](https://github.com/ReductTech/PaperSkill)。最终导入应保留完整项目，不只提交HTML或dist。
