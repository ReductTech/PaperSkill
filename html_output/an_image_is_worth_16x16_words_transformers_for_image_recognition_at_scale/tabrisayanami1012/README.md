# ViT：从图块到图像理解

基于 ICLR 2021 论文 *An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale* 的简体中文交互导读。使用 paper-skill 生成，React 18 + TypeScript + Vite；10章、19个完整小节、21个主动操作模块，附可复跑的 NumPy 验证与受控小实验。

2026-10-12 按用户要求按主题合并为10章；原19节全文、7组公式、21个交互及57条小节总结均保留。第5–7章共享输入选择和参数进度；其余低维手算仍是独立演示。只改目录层级、编号与指路措辞，没有把手工特征说成从照片学到的语义。

本项目回应上次 CLIP 反馈中的两个改进方向：增加实际代码证据；把“有局限”进一步写成有控制变量、指标和推翻条件的问题。不承诺评分提升。周复盘不嵌在网页中，阅读者完成哪些步骤，应由本人据实填写。

## 打开网页

在本目录执行：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5182
```

浏览器打开终端显示的本机地址。不要双击 index.html；它需要 Vite 编译 TypeScript。使用左侧目录或底部“上一章 / 下一章”；手机点“目录”。页面外的方向键可翻章，滑条内的方向键只改数值。

```powershell
npm run build
npm run preview
```

build 是自行部署时的可选构建命令。公开提交包含完整源项目，构建产物由托管流程生成，不提交本地 dist。

## 三类证据，不要混用

- **教学算例**：第2.2、3.1、4.1、4.2、8.1、8.2、9.1节为独立手算；第2.3节为手工像素滤波。第5–7章为连续两图块模型，只训练W_K中的一个数，不是像素到类别的端到端ViT。
- **本项目实验**：第9.2节结果由随附脚本实际生成；固定随机微型编码器，只训练线性读出。网页切换只查看记录，不会重新训练。
- **论文原表**：第10章保留 Table 2、Table 5 的不同训练与评估协议。原表分数不能与自造左右任务的正确率比较。

论文主线是有监督图像分类。ViT 可作为 CLIP 的一种视觉骨干，但 ViT 本身没有 CLIP 的文本编码器、图文对齐目标或零样本接口。

## 复跑实验

Python 与网页相互独立；网页不需要 Python 或 GPU。

```powershell
python -m pip install -r experiments/requirements.txt
python experiments/verify_vit.py --output experiments/results-local.json
python -m unittest discover -s experiments -p "test_*.py" -v
```

安装网页依赖后，还可以核对网页真正使用的计算函数：

```powershell
node experiments/verify_tutorial.cjs
```

该命令现有20项检查，包括新模型的输入投影、同份额不同V、连续分类、解析梯度与独立有限差分、8次真实SGD更新，19节内容无删减快照，以及章节注册、图块边界、位置交换、41种查询状态、LayerNorm、分类头、SGD、规格、原表数值及实验脚本哈希；不替代人工浏览器验收。已经执行的检查见 [验证记录](验证记录.md)。

建议 Python 3.12。不要覆盖 results.json：它是网页引用的原始记录。复跑到 results-local.json 后，比较断言、数据哈希和各组准确率；运行时长、平台字符串和极小浮点误差可随环境变化。

原始结果：无位置的五个初始化均为 50% 测试正确率；固定随机位置的均值为 99.6875%，样本标准差 0.698771 个百分点。此结果来自特别构造的成对左右辨别任务，**不是 ViT 原论文复现，也不能外推自然图像提升**。五个初始化共用同一数据划分，标准差不是置信区间。

完整方法、环境、哈希、限制与下一步问题见 [实验报告](experiments/实验报告.md)，原始数据见 [results.json](experiments/results.json)。
