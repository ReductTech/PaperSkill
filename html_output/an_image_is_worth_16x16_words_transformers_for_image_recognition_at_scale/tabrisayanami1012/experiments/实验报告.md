# ViT：从解释到可复核验证

2026-10-12。以下记录由本项目脚本实际运行生成。不是阅读者本人完成情况的证明，也不是 ViT 原论文的复现。

## 复跑

在项目目录打开终端，使用 Python 3.12：

```powershell
python -m pip install -r experiments/requirements.txt
python experiments/verify_vit.py --output experiments/results-local.json
python -m unittest discover -s experiments -p "test_*.py" -v
```

无需 GPU、预训练权重或下载数据集。原始记录保存在 results.json；复跑到另一个文件不会覆盖它。首次记录环境为 Python 3.12.14、NumPy 2.3.5、Windows 11、CPU、float64。首次完整运算约 0.77 秒，机器和 BLAS 实现不同会改变耗时与末位浮点误差；不要把它当成 ViT 训练耗时。脚本/数据 SHA-256 保存在 JSON 中。

## 验证一：是否真的保留了图块像素

对 3 张 8×8×3 数组，按 4×4 切成 4 个 48 维图块，再执行逆操作。最大绝对误差为 **0**。这验证展平是重排，不是取平均；不能证明随后的可学习投影保留全部信息。

## 验证二：线性投影与步长卷积是否等价

将同一个 48×7 权重矩阵重排为 4×4×3×7 卷积核，采用 kernel=stride=4、无填充、无偏置。比较逐图块矩阵乘法与逐窗口求和，最大绝对误差 **1.066×10⁻¹⁴**。这里说的“卷积”按深度学习常见互相关定义，不翻转核；加相同偏置时仍等价。

这解释为什么实现中可能出现 Conv2D，却仍不等于加了一个多层 CNN 骨干。形状、展平顺序、核步长或填充一旦不同，就不能套用本结论。

## 验证三：去掉位置后，交换图块有什么后果

构造随机的两层 Pre-LN 编码器，宽度 24、4 个头、每头 6 维、MLP 宽度 96；每层包含多头注意力和逐标记 MLP，均有残差；关闭 dropout。固定 CLS，只置换 4 个图块标记：

| 检查 | 最大绝对误差或差值 |
| --- | ---: |
| 注意力每行和减 1 | 2.220×10⁻¹⁶ |
| 无位置：CLS 输出差 | 2.442×10⁻¹⁵ |
| 无位置：图块输出与同一置换对应后的差 | 1.776×10⁻¹⁵ |
| 加固定位置：CLS 输出差 | 0.6376405722 |

前三项接近浮点精度，后者是同一随机模型的一次数值观察。原理：无位置且各标记共享变换时，置换只会同步改变 Q/K/V 的顺序；注意力与逐标记运算具有置换等变性，固定 CLS 的输出不变。加入固定槽位的位置向量后，交换内容不再是完整标记向量的相同置换，模型才可能区分顺序。不是任何参数都必然敏感；若把内容与位置向量一起移动，对称性仍可保持。

## 小实验：仅训练线性头，辨别红图块在左还是右

假设：如果两张图只交换同一批图块的位置，而标签依赖左右关系，那么不带位置信息的 CLS 表示无法可靠分开它们；位置可以提供破坏这一对称性的线索。

每张图 8×8 RGB，共 2×2 个图块。每对样本包含完全相同的图块集合，只有上方红、蓝图块左右互换；标签为“红在左=1，红在右=0”。颜色噪声和底部干扰图块随机生成，同对共享。训练 128 对（256 张），测试 64 对（128 张），数据种子分别为 13001 和 24002；先成对生成再按独立种子划分，不拆开同一对造成泄漏。

编码器种子 0–4，各种子两组使用完全相同的随机权重，唯一开关是是否加入标准差 0.2 的固定随机位置表。编码器和位置表均不训练；只用 CLS 特征训练零初始化的二分类线性头。标准化只使用训练集均值/标准差（标准差下限 0.05）。全批梯度下降 400 步，学习率 0.2，L2 系数 0.0001，偏置不正则。以上超参数预先固定，未按测试集选择最佳参数。预测前将 logit 四舍五入到小数点后 12 位，以免对数学上相同的样本用末位舍入差异假造可分类性。

| 编码器种子 | 无位置：测试正确率 | 有位置：测试正确率 |
| --- | ---: | ---: |
| 0 | 50.0000% | 100.0000% |
| 1 | 50.0000% | 100.0000% |
| 2 | 50.0000% | 100.0000% |
| 3 | 50.0000% | 100.0000% |
| 4 | 50.0000% | 98.4375% |
| 五种子均值 | 50.0000% | 99.6875% |
| 样本标准差 | 0.0000 个百分点 | 0.6988 个百分点 |

已观察到：本任务中加入固定位置的表示可被简单读出层利用；无位置组维持 50%，训练交叉熵约 ln2。所有初始化共用同一训练/测试划分，因此标准差只衡量这五次编码器初始化的波动，**不是泛化误差置信区间**。

没有验证：真实自然图分类、端到端 ViT 优劣、位置编码的最佳形式、CNN 与 ViT 的普遍比较。原论文训练位置表，本实验冻结随机位置表；原论文有远大得多的模型和数据。99.69% 不能与原论文 ImageNet 88.55% 并列比较。

## 验证四：高分辨率带来的序列账单

| 输入边长 | 图块边长 | 图块 N | 标记 S=N+1 | 每头注意力矩阵 S² |
| ---: | ---: | ---: | ---: | ---: |
| 224 | 16 | 196 | 197 | 38,809 |
| 384 | 16 | 576 | 577 | 332,929 |
| 224 | 14 | 256 | 257 | 66,049 |
| 518 | 14 | 1,369 | 1,370 | 1,876,900 |

固定 P=16，从 224 到 384，单头权重矩阵元素数约为原来的 8.58 倍。这不是总 FLOPs、显存或真实延迟的 8.58 倍：模型还有投影、MLP等运算，实现也可能不完整物化权重矩阵。更换分辨率时要按二维图块布局插值位置表，CLS 行单独保留。

## 现在能提出什么自己的问题

1. **空间关系是否比“物体是否存在”更依赖位置？** 本实验只检验左右关系。下一步在同一批配对输入上加入与位置无关的标签任务，用同等容量、相同划分比较差距；如果两类任务损失相同，原假设需要修正。
2. **更小的图块能否在相同预算下改善小目标？** 要分别训练合法的不同 patch 投影，固定数据/图像分辨率/调参预算，并按目标尺寸分桶评估正确率和实测耗时。不能直接改已有模型的 P 却沿用形状不匹配的投影矩阵；不能只看总准确率。
3. **小数据下的劣势有多少来自结构，有多少来自训练策略？** 同一数据子集、近似训练计算预算下，让 CNN 和 ViT 各自合理调参，报告多种子均值与标准差。只把两者强塞同一超参数不代表公平。

这些是待检验的研究问题，不是已完成结果。主论文依据为 [ViT v2](https://arxiv.org/pdf/2010.11929v2)：§3.1、§3.2、附录 A、§D.3–4；网页第10章单独保留论文评估结果及其协议。
