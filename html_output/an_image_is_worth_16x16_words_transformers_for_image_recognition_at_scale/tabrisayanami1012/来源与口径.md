### 位置消融：Table 8，PDF p.17

ViT-B/16 的 ImageNet 每类5样本冻结特征线性评估：无位置0.61382，默认一维0.64206，默认二维0.64001，相对位置0.64032。网页换算为百分数时乘100：61.382%、64.206%、64.001%、64.032%。这是该协议的结果，不能说无位置模型完全不会分类。

### 训练与计算量

- §4.1 与附录 B：Adam 预训练 β=(0.9,0.999)、batch=4096；JFT / ImageNet-21k / ImageNet 的 weight decay 分别为0.1 / 0.03 / 0.3。微调采用动量0.9的 SGD、batch=512。不能把 JFT 超参数泛化为所有训练。
- §4.4 与 Figure 5、Table 6：在论文考察的 JFT 训练架构和预算区间，以平均五数据集表现比较时存在有利的算力—效果折中；不保证所有硬件的推理更快。
- `S²` 是每头注意力权重矩阵元素数；还有投影、MLP 等成本。现代实现也未必将整个矩阵物化，因此它不是精确显存、总 FLOPs 或延迟。

## 本项目计算与论文之间的边界

2026-10-12按主题合并后的编号：第2.2节把人为亮度[1,2,3,4]用固定4×2表投影成[1.5,3.5]；第4.1节给定三个三维输入，经W_Q/W_K/W_V生成各块的三种向量。第4.2节默认查询、键和值直接复用这些结果。第2.3节用手工系数[0.5,0.5,−0.5,−0.5]测量2×2像素上下平均亮度差。上述均为教学例子，不是训练好的ViT图像输出。

1. 第3.1、4.1、4.2、8.2节向量都为手算用教学数据。第8.1节两段输出增量固定给出，用于解释残差，而非伪装完整学习网络前向。
2. 第9.1节是特征 f=1、标签为1、学习率为1、二分类线性头的单权重 SGD。它解释梯度，不模拟论文 Adam 预训练。
3. 第9.2节记录来自 `experiments/verify_vit.py`。冻结随机两层编码器和固定随机位置表，仅训练线性头；详细数据、种子和哈希见实验报告。没有做论文数据上的端到端训练。
4. 原论文关注分类；检测、分割列为未来方向。注意力 rollout 图也不是因果解释。自监督 masked patch 支线不等于 MAE 或 CLIP 对比学习。
5. 第10.1节三个问题是后续可检验假设。除了已报告的配对左右任务，其他自然图像、不同图块模型和公平调参对照均未执行。

### 第5–7章连续算例：明确比论文省略了什么

这是本项目新构造的数学模型，不来自论文原表或真实ViT权重。注意力与分类的一般结构依据论文§3.1、附录A；具体所有小数字、二分类规则和学习率由本项目设定。

- 输入两行：三角形[1,−1]，周围[0,c]；房屋c=+1，船只c=−1。未实现从照片产生这些特征的编码器。
- 固定W_Q=[1,0]ᵀ、W_V=[0,1]ᵀ；W_K=[a,0]ᵀ，仅a可训练。追踪三角形的查询行，d_k=1，初始a=2。
- 三角形份额u=sigmoid(a)，周围份额1−u；y=−u+(1−u)c。固定线性分类头分数为[2y,−2y]，第一项约定房屋，p(房屋)=sigmoid(4y)。
- 只用同一个房屋样本做8次学习率1的SGD；Q、V、输入、分类头均固定。梯度为8u(1−u)(1−p)，更新a←a−梯度；不是手调正确概率。
- 第0次p=4.5374%、损失3.092812；第2次p=53.8495%，由判错变判对；第8次p=93.7070%、a=−1.640415。船只在本构造下y恒为−1，仅是对照，不构成未见样本泛化评估。
- 8次后把房屋周围数值改为0时p=34.3072%；改为−1时p=1.7986%。这是特征层数值干预，不保证对应自然图片，也不是ViT鲁棒性实验。
- 省略位置、CLS、多头、输出投影、LayerNorm、残差与MLP；第8章和第9.1节再介绍完整架构。不能把两图块模型叫作完整微型ViT。
- 连续算例的选择与参数跨章共享，刷新重置；原有独立手算没有强行接进这条链。实现见vit-recognition-math.ts，梯度由独立有限差分核对。
