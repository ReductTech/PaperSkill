§1.噪声：扩散的起点推理基础

① 加噪 → ② 嵌入 → ③ 可逆 → ④ Flow → ⑤ CFG → ⑥ 采样 → ⑦ 训练 → ⑧ 共享权重 → ⑨ 技巧 → ⑩ 结果

本节作用
扩散模型的核心思想：训练时学会"去噪"，推理时从纯噪声出发一步步"去噪"生成文本。这一节展示加噪-去噪的完整循环，是理解后续所有章节的基础。
涂黑的字还能认回来
左边动画：先写好字→慢慢涂黑（加噪）→再擦回来（去噪）。扩散模型看千万张"涂黑→还原"的配对学会擦字。
