本节作用
§4 的网络能预测方向，但生成文本可能"跑题"。CFG（Classifier-Free Guidance）通过两次预测的差值放大，让网络更听话地遵循源文条件。这是控制生成质量的关键旋钮。
老师指导学生临摹字帖
学生自己临摹容易歪，老师（CFG）指导学生往正确方向写。其中参数ω越大越像字帖——字越工整，但太大就死板。论文实际用 CFG scale 1+2（self-guidance=1、input-guidance=2，条件生成）或 self-guidance=3（无条件生成）；下图 ω=2.5 仅作示意。

调 ω
v̂_CFG = v̂_uncond + ω × (v̂_cond − v̂_uncond)
v̂_CFG = 引导后的预测方向（沿差值方向外推） v̂_uncond = 不看源文 → 猜的方向 v̂_cond = 看源文 → 认真翻译的方向 ω = 引导强度
