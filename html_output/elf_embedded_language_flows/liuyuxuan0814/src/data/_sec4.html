§3.线性路径：为什么加噪是可逆的关键桥梁

① 加噪 → ② 嵌入 → ③ 可逆 → ④ Flow → ⑤ CFG → ⑥ 采样 → ⑦ 训练 → ⑧ 共享权重 → ⑨ 技巧 → ⑩ 结果

本节作用
§1 展示了加噪去噪现象，但为什么能去噪？因为 ELF 选择了直线路径（线性插值）。这一节解释：为什么简单的线性路径就能保证可逆，以及这如何导出 §4 的 Flow Matching 速度场。
直线可逆：沿直线加噪，沿直线去噪
毛笔从干净字直行到噪声端（加噪），再原路折返（去噪）。直线来回，路径确定——这就是线性插值可逆的道理。
3.1

交互：在 2D 嵌入空间看直线轨迹

加噪 = 从绿点（清晰的词）沿直线走到红点（纯噪声）；去噪 = 沿原路走回来。因为是直线，路上每一点的速度向量方向都一样，所以知道这个速度向量就能从噪声原路返回到词。

z_t = (1 - t) · ε + t · x_0
z_t = t 时刻的中间状态（线性插值） ε = 纯噪声（t = 0 时） x_0 = 清晰的文本（t = 1 时） t = 时间步：0 = 纯噪声 → 1 = 清晰文本（ELF 约定）
