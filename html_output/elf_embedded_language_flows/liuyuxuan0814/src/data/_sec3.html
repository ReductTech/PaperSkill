§2.嵌入：把词变成坐标推理基础

① 加噪 → ② 嵌入 → ③ 可逆 → ④ Flow → ⑤ CFG → ⑥ 采样 → ⑦ 训练 → ⑧ 共享权重 → ⑨ 技巧 → ⑩ 结果
🔗
本节作用
§1 展示了文字的加噪去噪，但文字是离散的（"我"和"你"之间没有中间值），无法做连续的数学运算。这一节解决：如何把离散的词变成连续空间中的点，使得后续的Flow Matching（微积分）能在上面运行。
词落在字帖上变成坐标
毛笔从墨池蘸墨，逐个送字入格。山、水、林各占一行——同类字颜色相同、紧挨一起。嵌入就是给每个词一个"格子坐标"，有了距离和方向，才能做连续数学运算。
