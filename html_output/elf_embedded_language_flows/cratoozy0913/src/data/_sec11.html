§8.共享权重 + 双 loss 训练核心创新

① 加噪 → ② 嵌入 → ③ 可逆 → ④ Flow → ⑤ CFG → ⑥ 采样 → ⑦ 训练 → ⑧ 共享权重 → ⑨ 技巧 → ⑩ 结果
🔗
本节作用
这是ELF的核心创新！同一个 Transformer 兼任两职：t<1 时denoise（在连续空间去噪，MSE 损失，服务 ODE 采样），t=1 时切 decode（输出离散 token，CE 损失，服务最终选词）。两者由 mode token 切换、共享同一网络权重——而不是两个独立模型。
一个网络干两件事：去噪+选词
同一支笔（共享网络），既能修正笔画（MSE，t<1）又能写出正字（CE，t=1）。去噪和选词共享权重，就像同一支毛笔写完一整幅字。
