# 事实证据与边界

- F1：开放词汇检测输入图像和文字，输出框与目标嵌入；部署可预编码自定义词表。来源：p2 Fig.2; p3 Fig.3。边界：词表可更换，固定部署词表不等于训练类别封闭。

- F2：对象与文本采用 L2 归一化点积，再乘可学习 α 加 β。来源：p4 §3.2 Eq.1。边界：s 为相似度 logit，不能直接当概率；非零向量。

- F3：每个四图 mosaic 训练样本采集正名词和随机负名词，默认最多 80 个名词。来源：p4 §3.2。边界：80 是训练采样上限，不是部署可识别类别上限。

- F4：T-CSPLayer 使用逐位置图文点积沿词表取 max，再 sigmoid 门控图像特征。来源：p4 §3.3 Eq.2。边界：门控与跨类别 softmax 不同；随后与跨阶段特征拼接。

- F5：三尺度各池化为 3×3，共 27 个 token；文本作为 query 更新 W′=W+MHA(W,X,X)。来源：p5 Eq.3。边界：图像相关文本不能无条件宣称对所有图像恒定。

- F6：离线词表可重参数化为卷积或线性层权重；部署避免逐图重复文本编码。来源：p2 Fig.2; p4 §3.2–3.3。边界：固定词表下的缓存；改词表需更新；教学线性等价不证明整网变为单层。

- F7：task-aligned assignment 配对；分类对比损失加 λI 乘 IoU 与 DFL 框损失。来源：p5 §3.4。边界：检测/grounding λI=1；图文数据 λI=0，原因是伪框有噪声；不是匈牙利匹配。

- F8：伪标签先抽名词、GLIP 产框、CLIP 筛相关性，再 NMS 去冗余；CC3M-Lite 246k 图像 821k 标注。来源：p5 §3.4 Table1。边界：置信度与正确性不能画等号；本篇不是复现标注流水线。

- F9：Table2：S 26.2 AP/74.1 FPS/13M，M 31.0/58.1/29M，L 35.0/52.0/48M。来源：p7 Table2。边界：LVIS minival Fixed AP，O365+GoldG；V100 无 TensorRT，正文默认无 FP16；重参数化。

- F10：Table2 L 加 CC3M-Lite 35.4 AP/52 FPS；原版 L 17.6 FPS/110M。来源：p7 Table2。边界：括号为原版，非括号为重参数化；不能把35.0与35.4混成同配置。

- F11：Table3：O365 23.5，+GQA 31.9，+GoldG 32.5，+CC3M-Lite 33.0。来源：p7 Table3。边界：L 消融协议；不能用33.0替代Table2的35.4或猜原因。

- F12：Table4 O365 无融合22.4；T→I23.2；双向23.5；GQA无融合29.7，双向31.9。来源：p7 Table4。边界：仅列已报告组合，新增耗时分别0/1.5/1.9ms，不虚构缺失项。

- F13：Table5 冻结BERT14.6，微调18.3；冻结CLIP22.4，微调19.3。来源：p7 Table5。边界：O365消融；CLIP微调下降3.1AP，不能推广为微调永远有害。

- F14：Table6 L O+G+C COCO零样本45.1；微调去RepVL53.3/156FPS。来源：p7 Table6。边界：COCO val2017；微调80epoch；FPS使用TensorRT，与Table2不直接比。

- F15：Table8 L仅分割头COCO16.2/12.4，LVIS19.1/14.2；LVIS全模块28.7/15.0。来源：p8 Table8。边界：Mask AP/APr，非检测box AP；需分割头及掩码标注微调。
