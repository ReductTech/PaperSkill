# Visual Agentic AI for Spatial Reasoning with a Dynamic API

中文交互教程：先构建可复用的空间函数，再通过程序和视觉工具回答复杂问题。

原文：https://arxiv.org/abs/2502.06787 （内容核对版本：v2）。公开署名：fangyuxin；GitHub：yx-1021。

## 运行

```sh
npm ci
npm run build
npm run dev
```

构建产物位于 dist。Vite 使用相对资源基址，支持放在版本子目录中部署。也可运行 npm run preview 查看生产构建。

## 内容与交互

封面、10 个完整章节和延伸视频共 12 页。每章内可纵向滚动，章节之间使用目录或底部按钮切换；保留原版字体、卡片与配色。开头是独立的紧凑概念动画，正文为可操作的机制演示。

- 动态 API：比较固定工具、逐题写程序与公共函数复用。
- 几何推理：自动演示或拖动椅子、滑块，观察深度与带参照尺度的高度估计；点击公式符号查看说明。
- 签名与依赖：切换请求，观察接口复用、缺失函数、占位测试和恢复外层调用。
- 两阶段协作：区分 API 生成与解题程序的合成、执行，图像在执行时由视觉工具读取。
- 语义检查：切换排除参照物并移动区域边界，核对候选与计数。
- 实验解读：切换六组评测条件；拖动预测值检查 MRA 的严格阈值。

第 1 章读取深度前显示“待读取”；第 2 章 loc 返回坐标列表；理想诊断图表区分程序方法与同样本 VLM 对照。系统减少动态效果设置下默认暂停，仍可手动播放。

## 内容边界

动画中的家具、人物、工具和数值算例用于解释机制，不调用真实 VADAR 或视觉模型。尺寸换算依赖同焦距、可比较投影方向和题设参照尺度。运行测试通过不等于空间语义正确。

实验数值保持对应的样本量、视觉条件和指标；不跨 500 题真实视觉与 50 题理想诊断子集直接计算提升。VSI 展示仅对应 75 题单帧子集。免训练指组合阶段不更新目标任务权重，系统仍依赖预训练模型。
