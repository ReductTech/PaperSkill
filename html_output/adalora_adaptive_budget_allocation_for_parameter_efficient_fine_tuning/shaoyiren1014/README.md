# THE ADAPTIVE ENGINE — 自适应引擎

有限的预算，如何做出最重要的改变？

当前默认版本是 **阿达的改装旅程（ACT 0–9）**。读者保留机器人已有的机械脑，逐步安装小型更新旁路、通道分配盘、贡献控制器、巡检记忆和预算调度器，再用论文证据检查设计，并留下自己的工程说明。

每章一个主要操作，主线使用通俗结论、SVG 机器人与机制动画。原始实验数字、次要实验、复杂公式和控制条件在可选档案中；预测与章节工程日志选填，ACT 6–8 不要求逐项完成实验。

保留：连续布局、桌面/手机适配、键盘操作、渐进解锁的知识补给、路线图、本章重置、环境声开关、减弱动画、本地保存、旧版记录导出、可打印报告与 JSON 报告。

新版使用独立存档，不把旧版完成状态当成新版已经体验。旧记录仍在原保存位置，并在工程日志中保留快照。重置本章归档当前记录及装配配置，不影响其他章节或旧版记录。

机器人和人工巡检、预算、分布示意是教育模拟，不输出模型准确率。原始证据来自 AdaLoRA v2 的 Figure 1–3、Table 1–5 和 Table 15 的 MNLI 行；预算、指标、控制条件与例外都留在档案中。最终工程批准表示学习审查完成，不是实际模型效果认证。

## 本地运行

```text
npm install
npm run dev
```

生产构建：`npm run build`。
新版逻辑检查：`node scripts/check-robot.mjs`。
既有 `check-act0.mjs` 至 `check-act9.mjs` 保留作旧版状态与原有证据记录检查，不代表新版交互入口仍使用旧关卡。

设计和逐章五问检查：[design/Robot-Revision.md](design/Robot-Revision.md)。旧版文档、截图和源入口作为历史保留，不是当前默认网页的说明。
