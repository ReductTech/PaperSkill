## ACT 1：LoRA 回顾并入模块议会

从 ACT 0 过渡：先别急着决定谁应该得到更多。用几分钟看看机器里有哪些部门，LoRA 又在改哪里。

1. 认识机器：Transformer 像一层层重复的小处理单元。点击一层展开 Attention（找哪些信息彼此相关）与 FFN（加工每个位置的信息）。残差等细节放技术抽屉。
2. 找到 LoRA：主矩阵旁出现小型更新支路。切换全部调整与只调旁路；冻结主参数始终可见。LoRA 更新作用于选定权重矩阵，不是只放在层间的独立 Adapter。
3. 看为什么省参数：预测后比较教学尺寸 64×64 的 4096 参数与 Rank=2 两小矩阵 64×2、2×64 的 256 参数。标明是教学例子，不含偏置等额外项。直觉：不重改整张大表，只训练两张小表，它们合起来描述这次要改的部分。
4. 发现问题：同尺寸矩阵采用相同 Rank，是旧配置规则，不是所有 LoRA 实现都只能如此。相同 Rank 对不同尺寸矩阵未必对应相同参数量；不能说成每个原始权重被平均修改。
5. 进入模块议会：省钱的办法已经有了，现在问省下来的改动容量放在哪里更值得。进入原 ACT 1 的 Figure 1 预测、观察与范围修正。

## 所有公式紧邻直觉解释

| 简式或结构 | 通俗解释 |
| --- | --- |
| W = W₀ + BA | 原来的大矩阵不动；两张小表合起来补上这次任务需要的改动。 |
| r × (d₁ + d₂) | 每多开一个调节通道，就需要为它准备两侧的小参数表。 |
| ΔW = PΛQ | Q 从输入的某个方向取信息，P 决定往输出的哪个方向改，Λ 控制改动强度。 |
| 权重与梯度乘积绝对值 | 粗略估计把参数归零后损失受多大影响，不是实际删除的因果测量。 |
| 平滑敏感性 × 变化项 | 既看历史记录，也保留当前与历史不同的信息；不是简单惩罚所有波动。 |
| λ 分数与 P/Q 两侧均值汇总 | 判断整个方向不能只看中间旋钮，也要看两侧参数。 |
| top-b(t) | 当前预算允许多少，就从全局挑优先级较高的那么多方向。 |
| 三次下降调度 | 先留探索空间，再逐渐收紧，最后保持分配并继续优化。 |
| 正交正则 | 尽量让不同调节方向少重复；这是鼓励，不是完美保证。 |

默认不展示推导。证据先一句话讲为什么看，再一句话讲支持什么，最后一句话讲不能保证什么；条件、原值和来源可展开查看。

开场：这章不用先记公式。你只需要想一件事：资源不够时，每个部门都分一样多，真的合适吗？

操作反馈：你改变的是资源放在哪里。现在没有训练模型，不能说哪个方案效果更好。

证据概括：研究者把同样数量的可训练参数放到不同位置，得到的结果不同。除了省参数，还要考虑把参数放在哪里。
