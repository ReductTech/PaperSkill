## 分段与通俗过渡

入口 → 认识一层的两个部分 → 原矩阵旁的小支路 → 先预测、再数参数 → 预先设定相同 Rank 的问题 → 模块实验 → 层组实验 → 修正认识 → 解锁发现。

默认不要求阅读公式。技术抽屉中的 `W = W₀ + BA` 与参数数目简式均紧邻通俗解释。FFN 与较高层的优势只描述为本实验中的观察，不推广到所有任务。
