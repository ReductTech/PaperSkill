| 教学检查 | 本章回答 |
| --- | --- |
| 用户会产生什么问题？ | 大的方向是否更重要？一次训练的信号够不够？历史信息是否保证正确？ |
| 用户做出了什么主动判断？ | 第一次选择评分方法；主动切换三种方法、逐组观察；辨别模拟只能说明排序；预测完整评分的实验表现；最终修正优先级与准确率之间的关系。 |
| 用户得到了什么论文证据？ | 上传 PDF 第 5 页 Section 3.2 Eq. 7–11 的敏感性、平滑、变化和整方向聚合；第 9 页 Table 4 中三种评分的 SST-2、RTE、CoLA 对照，27 个原始数值。 |
| 用户最终理解了什么变量关系？ | 参数值与梯度共同形成局部敏感性近似；历史平滑和变化项相乘后逐参数评分，再加 λ 分数与 P/Q 两端平均分。排序用于当前保留优先级，不能直接推成准确率。 |
| 教学模拟是否被当成真实实验？ | 四方向六组信号、初值、EMA 系数、两条保留预算均为人工设定；没有真实重要性标签或训练成绩。机制说明和实际 Table 4 各自有来源标记，不给用户的暂选集合评分。 |

## 主线与纠偏

提出问题 → 保存预测 → 三方法与六组信号比较 → 观察判断 → 论文机制 → 再预测 → Table 4 → 修正认识 → 点亮发现。

所有第一次预测均不可改写，错误预测不会跳过知识。观察与修正阶段的错误会触发解释，需要改为有条件的结论才能完成。技术公式全部在可选抽屉里，每式紧邻直觉描述。

- 不把大小等同于任务价值。
- 敏感性是参数归零对当前损失影响的局部近似；不是每次删参数重新训练的实测，也不证明严格因果。
- 变化项采用局部偏离的平滑估计，参与乘积，不是波动扣分或严格置信区间。
- 先逐参数计算 EMA、变化、乘积，再对 P/Q 求均值，避免错误地先聚合信号再求乘积。
- 不保证历史法排序总最稳、完整评分每次更好。Table 4 对仅敏感性有七个更高、一个持平、一个略低；对仅大小九格更高，只限这组记录。
- RTE 0.08% 的 87.36/87.36 和 0.65% 的 88.09/88.10 都保留。微小差值不证明统计显著。
- 人工仪表每组按最高分缩放；不同方法分数尺度不同，界面提醒只比较方法内部排序。
- 真实证据按研究问题、控制变量、相对表现、趋势、条件和原文位置组织；SST-2/RTE accuracy 与 CoLA MCC 分开，不跨任务比较。
