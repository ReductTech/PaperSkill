# Grounding DINO 交互式论文导读

面向已有目标检测基础的读者，按 10 章解释语言条件检测、特征增强、查询选择、文本注意力、跨模态解码、训练匹配及论文实验。制作署名：GitHub [Lipeilin0307](https://github.com/Lipeilin0307)。

## 本地运行

使用 Node.js 20.19+ 或 22.12+，推荐配合 pnpm：

```sh
pnpm install
pnpm dev
```

根据终端给出的地址打开页面。`pnpm build` 生成 `dist/`，`pnpm preview` 预览构建产物。也可使用 npm 执行同名命令。

## 内容与来源

- 论文：[Grounding DINO](https://arxiv.org/abs/2303.05499v5)，ECCV 2024，本文对照 arXiv v5 的章节、公式和实验表。
- 机制交互中的公园场景、相似分数和框更新是人工教学示意，不运行模型、不代表预测成功率。
- 第 9–10 章数值来自论文表 2–7；界面显示对应骨干、训练数据和评测协议。AP 与指代定位准确率分开展示。
- “零样本”采用原文的数据集迁移定义，不保证类别在全部预训练数据中都未出现。
- 视频链接用于辅助学习，视频观点不替代原论文证据。

## 操作提示

目录可直接跳转章节；选择按钮、候选数量滑块、逐步解码、拖框及对比图会立即更新反馈。拖框提供方向按钮，所有按钮可键盘操作。自动类比动画遵循系统的“减少动态效果”设置，滚出视口时暂停。

## 本周实验衔接

后续在固定检查点上对照 YOLOE 与 Grounding DINO，分别评估类别名、属性描述、关系描述。先标真值，记录模型/权重版本、输入分辨率、提示与阈值，再统计成功率、漏检、误检和定位偏差。模型置信度不等同于跨模型可比概率。本网页本身无需 GPU；真实模型推理是另一个实验。
