## 教学构造与实测边界

- 观鸟场景、鸟形、查询点积小矩阵、解码器缩框轨迹、二乘二匹配成本均由教程人工构造，只演示论文所述操作顺序，不代表 Grounding DINO 实际推理或训练记录。
- 查询实验从四个图像 token 中选 Nq，论文默认 Nq=900；切换示意矩阵不会改变论文报告值。
- 论文 Table 2 的 60.7‡ 使用 COCO 训练数据，明确不是真实零样本；52.5 对应另一种 L 模型及数据配置。
- 表 3 中整体 AP 与稀有类 APr 分别看；表 6 的三个 AP 属于不同数据集，不直接按大小比较。
- 用户预览认可、自动浏览器测试与论文事实独立核验是不同证据；本次未声称用户逐项核对。
