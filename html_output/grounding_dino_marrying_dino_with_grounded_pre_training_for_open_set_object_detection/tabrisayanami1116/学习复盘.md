# 这周的学习复盘

这周接着 DETR 学了 Grounding DINO。上次主要看一张图里有几个人、几辆车，模型怎样把框画出来。这次换了一个问题。图里有三颗苹果，我只找红苹果，或者只找右边的那一颗，模型怎么知道该给谁画框？

我先从图和词怎样变成向量看起。照片上不同大小的区域会变成视觉特征，像“red apple”和“green apple”这样的提示会拆成多个 token。同一句输入里可以放多组短语，文本注意力可以让每组的颜色和类别保持联系。红组里的“apple”能读到“red”，绿组里的“apple”会读自己的颜色词。

最能接上上次学习的是目标查询。原来 DETR 有一组会学的查询。这次先拿图上每个位置的向量和各个词做点积，在每个位置取最高分，再挑分数靠前的位置来初始化锚框。查询还有一个可学习的内容向量。到了后面的解码层，它会继续读图像和文字，把框的位置一步步细化。用三个位置和两个词把矩阵展开后，先取最大、再排序这两件事就好区分了。

另外用公开 Tiny 权重跑了 14 次推理。合影里输入“左边的人”，模型给两人都画了框，最高分还落在右边。左右翻转照片后，同一条提示的第一名变成画面左侧，但其实还是同一个人。苹果那张也很有意思。“红苹果”的第一名确实是红的，两颗绿的却也过了框阈值。把红和绿写成两组提示时，标签把三个框按颜色分开。图里没有香蕉，输入“香蕉”时还留下了三个框。通过这几组结果，我学会了把提示词、分数和框的位置放在一起检查。

看论文成绩时，我也区分了零样本检测和指代定位。前者要看整个数据集上的检测表现，后者要看每句对应的首选框。小实验里两个框都过阈值但第一名选错的情况，让我更容易理解这两个任务为什么需要各自的评测。
