# TraDiE 中文交互式论文导读

王艺霖制作的《Towards Metric-Agnostic Trajectory Forecasting》中文交互式导读，共 5 章、17 页，使用 React、TypeScript 和 Vite。

论文：Markus Knoche、Daan de Geus、Bastian Leibe，ECCV 2026。原文为 [arXiv:2607.01133](https://arxiv.org/abs/2607.01133)，本导读依据 v1；作者项目页为 [TraDiE-policies](https://vision.rwth-aachen.de/TraDiE-policies)。

## 内容与交互

1. 指标冲突：移动同一个预测终点，对照最近距离与容差窗口命中；在固定分布、相同输出名额下比较两种候选摆法。
2. 解耦动机：依次解释为什么保留未来分布、怎样学习，以及怎样在不更换模型权重的情况下按用途选择输出。
3. 分布学习：观察位置尺度与预测航向，运行一维混合模型的 WTA 回归或 NLL 训练，比较 Traj-NLL 与 Step-NLL 的时间混合顺序。
4. 输出选择：改变整数候选预算，拖动或优化终点；逐轮选择覆盖剩余窗口最多的候选，并核算新增命中对应的置信度。
5. 证据与边界：对照论文表 1 和表 4，说明同一权重的两套策略提交、多时域配对及分布失配的影响。

顶部翻页、侧栏缩略图选页，讲稿入口提供详细解释、原文章节和示例边界。每页采用 1600×900 固定画布；支持全屏演示、画布缩放和放大后移动。候选数量及选取轮数使用整数按钮，连续量使用滑块。

## 教学计算与论文结果的边界

- 路口、车辆、坐标图、分布样本与训练观测均为代码绘制或生成的教学数据。网页中的 96 个终点样本、1–4 个候选及可调容差框，用于说明计算；并非论文实验数据，也不是 Waymo 官方阈值。
- 距离目标计算未平方的欧氏距离：每个样本取到最近候选的距离，再对样本平均。优化时固定样本及预测模型，只移动输出终点。原文使用 3000 个样本、6 个候选和多次随机初始化；网页采用较小的可交互算例。
- 窗口按每个样本的假想真实位置和航向定义；每轮选择落入最多剩余窗口的样本位置。置信度分母始终是原始样本总数，置信度之和可以小于 1。命中覆盖数不等于 mAP。
- 一维训练页是固定尺度的 Laplace 混合小模型，以数值梯度说明训练如何改变均值与权重，未运行 DONUT。WTA 按钮只演示回归赢家；原论文还有模式权重分类损失。
- 排序页的 AP 是两个模拟场景的简化计算，未完整实现 Waymo 的平滑、类别分桶与评测协议。
- 表 1 为 Waymo 验证集、DONUT Laplace 的原文结果。表 4 为 Waymo 测试集、Step-NLL 与广义高斯的原文结果：窗口策略的 soft mAP / minFDE 为 0.5018 / 1.3280 m；距离策略为 0.1649 / 1.0304 m。两行使用同一组模型权重，但候选输出不同，不能解读成同一套候选同时消除了指标取舍。
- 多时域连线是排名配对示意，不保证中间轨迹连续或满足动力学。失配页的真实分布只用于教学对照，不是推理时可用的输入。策略收益依赖预测分布质量。
