## 教学模型

交互均使用浏览器中的确定性规则。文件风险属性、后台门槛、请求次数与算术缺陷是明确设定的教学例子，不能作为 Claude Code 的实测结果或生产安全保证。SVG 图形全部原创，无第三方字体、图片、视频或运行时 CDN。没有网络命令执行、登录或数据收集。

## 展示修订

根据 [Sprouts 论文分享指南](https://grokcv.site/sprouts/guide/)和 [Yuhan 的分享建议](https://grokcv.site/sprouts/yuhan/)调整为 7 章、12 页（含封面），保留 8 个可操作教学模块。

- 每页围绕一个问题，用结论式标题和短句呈现；操作步骤、来源定位、推演边界和转场放入讲稿。
- 使用统一的无衬线字体、蓝灰主色与对齐网格。正文为 32 CSS px（固定画布上相当于 24 pt）；绿色和红色仅表示通过与风险。小屏通过播放器缩放阅读。
- 减少旋转和重复动画；封面演示一轮后停留，交互只保留短暂反馈与必要的因果变化。
- 补全作者、载体、日期、文章类型和机构信息边界；新增防线收益/盲区比较，以及明确标为未实施的 2 × 2 后续实验设计。
- 建议分享时长为 12–15 分钟，逐页讲稿包含建议时长、操作、停顿和过渡。可用播放器的讲稿面板辅助排练。

两份参考中的论文筛选和 PPT 文件命名属于其活动要求；本项目遵循 PaperSkill 的交互网页格式。原文的博客属性保持如实标注。
