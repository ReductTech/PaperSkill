# MiniMind-O 论文助教的核对资料
基准：MiniMind-O Technical Report: An Open Small-Scale Speech-Native Omni Model，Jingyao Gong，arXiv:2605.03937v1，17 页。以下页码指 PDF 页码。

- 输入文字、语音和图片，输出文字与语音。小规模主模型有利于研究可检查的多模态链路，不代表通用能力与大型模型相当。p1 摘要、p2 图1。
- 默认 Thinker 为 8 层、hidden 768，Talker 为独立 4 层。理解/文字生成与音频码生成分工。Talker 接收 Thinker 中间隐状态及自己的音频码历史，不是把最终文字单独交给 TTS。p3 图2、p13 表6。
- 音频由冻结 SenseVoice 提取 512 维特征，经可训练投影器接入 768 维隐空间。图像使用冻结 SigLIP2；256×256 输入对应 64 个图像位置，接入向量维度 768。文字经词嵌入。位置数与维度不能混淆。p5 §3、p13 表6。
- 默认桥接零基层 N//2−1=3，即第4层之后。浅层较偏 token 身份、上下文尚在积累；末层偏向下一文本 token 分类。作者讨论桥接过深增大 CER，但没有完整逐层 CER 数表，不能制造逐层分数。桥接不截断 Thinker 后续层。p5 §3.1。
- Mimi 使用 8 层码本，12.5 帧/秒，24 kHz；一帧覆盖 80 ms，完整八层码共同解码。码值是离散索引，不代表音量或音高。80 ms 覆盖时长不等于首包延迟。p4 图3、p6 §4。
- 教学延迟图用 s=0 表示首个文字步，q=0…7，零基帧 f：s=f+q+1。同一帧沿斜线组成，第一帧在 s=8 集齐。完整帧数 max(0,s−7)。教程第12步结束是人为教学边界，不是实测系统结束。p6 §4、公式1及其教学索引展开。
- CAM++ 192 维说话人向量预计算，填入说话人条件位置；参考音频码在目标前右对齐。参考条件不计音频目标损失；有效目标码计入损失。损失掩码不等于删除条件。p5 §3、p6 §4。
- 共享接口主体+码本专属低秩修正。一般矩阵示例：m×n 修正需要 mn 个参数，m×r 与 r×n 分解需要 r(m+n)，只计修正部分。r 越大不一定节省更多。
- 图8(f) 冻结 Thinker、A2A 子集的秩配置 audio loss：E16/H16=5.453；E16/H256=5.100；E256/H16=5.353；E256/H256=5.002。E 嵌入端秩，H 输出头秩。不是 CER，也不是独立/共享结构的直接性能比较。
- T2A 文字到语音、I2T 图片到文字、A2A 语音到语音是任务；all、audio_proj、vision_proj 是更新范围。SenseVoice/SigLIP2/Mimi 始终冻结。冻结不等于不参与前向计算，仍可传递到投影器的梯度。I2T 无目标音频。论文训练概述与实现脚本模式不能拼成唯一固定流水线。p6 §5、p7 表1。
- 表2 Dense Talker宽度768/512/384：CER 0.0897/0.1745/0.2767，检查点参数115.29/96.13/88.72M。MoE对应CER 0.0900/0.1265/0.3280，参数317.05M总量-115.33M激活、261.32M-96.17M、240.04M-88.75M。内部一致性由生成语音的 ASR 转录与 Thinker 文字比较。低CER不等于好音质。p8表2。
- 约0.1B不包含冻结外部组件。组件参数量与检查点标签口径不同，表6不可直接替代表2标签。
- 表3 CAM++音色相似度 Dense seen/unseen/overall=.6472/.5654/.5995；MoE=.6267/.5702/.5937。5 seen与7 unseen，不是MOS听感评分。
- 表4：20个简短英文问题T2A，MiniOmni CER/WER .0101/.0185，MiniOmni2 .0371/.0431，MiniMind .0964/.0973。表5：9张合成图片、Qwen-VL-Plus构造长度匹配参考，MiniMind .8241/1.0293，MiniOmni2 .7609/.9756。不同协议不可混合排名。p9–10表3–5。
- CER=(替换+删除+插入)/参考字符数；WER以词计，插入可使其大于1，不是准确率或概率。不能推出自然度、理解正确性或系统延迟。
- 教程固定案例、矩阵尺寸示例、动画、波形示意并非额外实验。官方Gradio体验非实时，不用它测量流式延迟。本地保存的2026-09-14测试语音是1.92秒音频长度，不是推理时间。
