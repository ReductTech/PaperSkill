# JOCA：相机硬件与自适应控制的任务驱动联合优化

这是给论文 JOCA: Task-Driven Joint Optimisation of Camera Hardware and Adaptive Camera Control Algorithms 做的十章中文交互式 PaperSkill。作者为 Chengyang Yan、Mitch Bryson 和 Donald G. Dansereau，发表于 WACV 2026。

- [作者项目页](https://www.roboticimaging.org/Projects/JOCA/)
- [论文全文](https://arxiv.org/html/2512.06763)

网页旨在帮人弄懂论文，不运行原模型。夜间巡路图、可调滑块和 DF-Grad 步骤图都是教学示意；第九章注明来源的 mAP 才是论文报告值。

## 打开

Windows 可双击本目录的“打开网页.cmd”。它会运行 Vite 本地服务器并打开浏览器。请保持弹出的终端窗口运行；结束后可关闭。不要直接双击 dist/index.html，也不要把构建后的 JavaScript 粘贴进 HTML 文件。

也可以在本目录运行 npm install，然后运行 npm run dev -- --host 127.0.0.1 --port 5179 --strictPort，最后打开 http://127.0.0.1:5179/。npm run build 可以检查 TypeScript 并构建静态资源。

## 我这次具体改了什么

上次反馈认为工作量仍可再加强，尤其是比较方法、实验设计和与主动视觉课题的接口。因此这次不只做十段摘要：第 1、3 章让人看到亮度、噪声与拖影的拉扯；第 5–8 章分开追踪硬件、控制器和检测器的训练信号；第 9 章仅在同协议内列基线与消融；第 10 章把自己的四个疑问转成对照组和可测指标。章节文字尽量先说具体困惑，再接论文方法，不用空泛的“显著提升”代替条件。

| 条件 | 结果 | 来源 |

| CARLA，标定噪声与模糊 | FLIR+NeuralAE 0.318；Basler+NeuralAE 0.289；TaCOS+AverageAE 0.303；JOCA 0.325 mAP | 论文表 1 |
| Waymo，标定条件 | Basler+NeuralAE 0.316；TaCOS+AverageAE 0.297；JOCA 0.331 mAP | 论文表 2 |
| Waymo，噪声 ×10 | 0.303；0.308；JOCA 0.322 mAP | 论文表 2，同上顺序 |
| Waymo，噪声 ×20 | 0.272；0.289；JOCA 0.319 mAP | 论文表 2，同上顺序 |
| CARLA，标定条件消融 | 去 GA 监督 0.310；固定扰动 0.302；冻结检测器 0.233；完整 JOCA 0.325 mAP | 论文表 3 |

上述 mAP 越高越好；CARLA 与 Waymo 不跨表直接相减。CARLA 测试集为独立城市地图上的 1000 张图像；Waymo 使用约 550 张测试图像，并以图像后处理模拟候选相机的分辨率、噪声和运动模糊。后者不是新造硬件的真实外场测试，原文也说明结果受模拟保真度限制。第六章四个扰动候选、每四步加入 GA 监督，第七章每四十五步更新硬件，都是论文实验设置，不是通用最佳值。

## 与主动视觉的关系：我的判断

JOCA 确实迈向主动视觉：它不把相机当成永远不变的输入端，而是让曝光和增益根据场景变化，且以最终检测任务作为评价。但硬件选型主要是离线搜索，论文并未验证智能体主动改变视角、采样时刻或车辆行动的完整闭环。所以我把它称作“任务驱动主动成像控制”，不直接称作完整主动感知智能体。

接下来值得做的实验是：固定相同硬件与检测器，对照仅调曝光、曝光加视角联合控制、以及 JOCA 原设置；在新传感器、隧道明暗突变、快速运动三类场景分别报告 mAP、恢复帧数、漏检率、控制耗时与功耗。这样才能检验“任务收益”是否经得起跨设备与成本约束，而不只看平均检测分数。这是我的延伸方案，不是论文已有结论。

## 制作记录

1. 对照论文 §3–6、图 2、表 1–3 和附录 B，先整理固定变量、动态变量、训练信号与结果条件。
2. 把容易混淆的“本帧/下一帧”、“示意值/论文值”、“CARLA/Waymo”分别放到交互提示和结果来源里。
3. 第一版内容用工厂函数编排；结构验证器要求显式章节点，故机械展开为数据对象。随后通过结构验证和 TypeScript/Vite 构建。
4. 尚未复现作者的检测器训练，也没有实测相机硬件；网页交互只承担导读功能。提交前仍需由本人核对事实、电脑和手机显示及交互。

项目使用 React 18、TypeScript 与 Vite，正文在 src/data/tutorial.ts，交互在 src/modules/joca-widget.tsx。没有外部图片、在线字体或运行时第三方服务。
