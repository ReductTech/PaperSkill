# ProxyCLIP 中文交互教程

制作：尹灿宇（AI辅助）。ECCV2024正式版，10章20个主要互动模块，另含分布与预算两个嵌入实验。主题为开放词汇语义分割、代理注意力、归一化与mask、分辨率对齐、冻结推理、消融和结果证据。

Node.js 20+；npm ci，npm run dev；npm run build。桌面端验收。React/ReactDOM为唯一运行时依赖，无CDN、无模型权重或在线推理。

所有二维向量、像素画、涂画掩码、对应矩阵是教学构造，不是论文分割输出。实验表为正式论文原始报告值，各附表号和协议。无mask的softmax平移不变是代数推论。全屏蔽、零向量和空候选集均单独显示未定义状态。

源码提交前必须使用当前上游资源路径校验；本项目模板注释中的图片示例已改为相对路径。投稿paper.json对应participants[].jianlunId必须填写用户提供值并核对远端；身份不嵌入正文。

详细事实来源见EVIDENCE.md。教程本身不是研究复现，也不声称当今最优。
