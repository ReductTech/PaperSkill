# CoOp：让提示学会适应任务

面向论文初读者的中文交互式学习网页，使用 React 18、TypeScript 和 Vite。包含 10 章、11 个主要互动模块、可逐项查看解释的 LaTeX 公式与延伸视频。

## 打开网页

Windows 下双击本目录的 `start.cmd`。已安装 Node.js 时，它会启动本地服务并打开浏览器；首次缺少依赖时会先安装依赖。关闭服务终端即可停止预览。

也可以在本目录执行：

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5174
```

打开终端显示的地址，通常为 `http://127.0.0.1:5174/`。请通过本地服务访问，不要直接双击 `index.html`。

```bash
npm run build    # 类型检查并输出 dist/ 静态站点
npm run preview  # 预览构建结果
```

请保留完整项目文件夹。迁移电脑时可以不复制 `node_modules`，重新运行 `npm install` 即可。教学内容和交互无需 API 密钥或 CLIP 权重；外链视频及其缩略图需要网络。

## 建议学习顺序

| 章节 | 学习问题 | 主要操作 |
| --- | --- | --- |
| 1 | 提示措辞为什么重要？ | 切换真实模板与数据集，比较报告准确率 |
| 2 | 文字怎样变成模型输入？ | 逐步展开文字、词嵌入与软提示 |
| 3 | 固定模型怎样响应新输入？ | 拖动共享上下文，观察类别特征联动 |
| 4 | 相似度怎样变成概率？ | 调节竞争类别分数，观察 softmax 与损失 |
| 5 | 共享提示还是每类一套？ | 调一个数值，对照共享与独立参数的响应 |
| 6 | 推理阶段会改变提示吗？ | 选图自动推理，点阶段复看，观察固定文本特征 |
| 7 | 一次错误怎样更新提示？ | 前向、损失、梯度、更新四步训练 |
| 8 | 冻结为什么仍能求梯度？ | 按引导运行连通 / 切断两组实验，对照更新结果 |
| 9 | 更长提示是否更好？ | 比较真实迁移结果，判断域与类别变化 |
| 10 | 实验支持怎样的结论？ | 检查正负收益、计算标注预算、判断结论 |

每章按“问题—机制动画—操作—解释—要点”展开。建议先操作再看公式，证据细节默认折叠。顶部数字按钮直接切换页面：0 为封面，1–10 为正文，11 为延伸视频；悬停可查看标题，当前章节会高亮。手机自动排成两行。画布拖动同时提供按钮或键盘替代。

封面和十章章首使用同一条 7.8 秒的循环时间轴。插图与进度线同步播放，也可点选阶段直接复看。滚动离开动画或切换到后台时会暂停计时，返回后从原处继续。系统启用“减少动态效果”时默认静止，可手动选择阶段或主动播放。

正文实验中的词块插入、特征移动、损失变化和梯度传递都与操作关联。顶部数字目录可随时换章，章末也有上一章／下一章按钮。正式公式逐行展示，用 KaTeX 在本地排版，数学字体随网页打包。鼠标移到符号上或用手指轻点即可查看释义。使用键盘时，按 Tab 进入公式，再用左右方向键逐个读符号，Esc 收起释义。

## 数值与证据的边界

- 论文数据附有图表、页码和实验条件。准确率与“准确率差值的百分点”分别标明；小样本 CoOp 使用标注，零样本 CLIP 对照不使用下游标注。
- 二维上下文、文本特征、概率与训练损失来自一个固定的微型可微模型，明确标注为教学模拟，不能视为真实 CLIP 结果。编码器固定，只有上下文参数更新。
- 教学模型使用 `h_i = tanh(A V + b_i)`、平滑归一化、分数 `3〈w_i,f〉` 和交叉熵；梯度经过归一化与 tanh 精确计算。不同类别对梯度的贡献相加得到共享上下文梯度。
- 迁移实验与未参加适配的新类别实验分开解释；主文 few-shot 与附录 DOSCO-2k 的协议分开呈现。保留 Food101 等反例，不推导所有任务必然受益。
