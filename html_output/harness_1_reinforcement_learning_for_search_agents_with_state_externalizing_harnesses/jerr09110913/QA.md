# 构建与验收记录

以下2026-09-14内容是历史验收，不代表之后每一版源码均保持这些条件。当前状态以文末2026-09-15修订记录为准。

## 本轮范围与决策

从官方 paper-skill 模板创建独立目录，不复用旧项目实现。结构为9章、10个主动模块，正文模式分布如下。

| 章节 | 主交互模式 | 可观察的状态变化 |
|---|---|---|
| 1 | P2 步骤控制 | 查询、阅读、提交与回退修订 |
| 2 | P5 热点路径 | 同基线的搜索/回看改变返回来源与P/D差分 |
| 3 | P3 同步对比 | 相同事件同时更新累积历史与角色状态 |
| 4 | P6 拖动探索 | 预览/提交重要性，拒绝或替换精选成员 |
| 5 | P5 关联热点 | 实体边、文档原句与按主张核验记录 |
| 6 | P1 预算调整 | 真实字符计数驱动五阶段输入构建 |
| 7A / 7B | P4 离散情形 | SFT样本边界与RL终局/组内信号 |
| 8 | P2 运行与修订 | 作者快照和独立练习，阅读后显式精选 |
| 9 | P8 结果比较 | 同协议结果、百分点与反例 |

覆盖7种主模式，P1仅1章。P7只用于辅助生活动画。

早期版本采用第1、2、3章主模块生活引入与第9章生活收束；这一“四处联动”的历史记录已被后续修改取代。封面结合生活记录与技术目的。其余主模块保持技术对象，各章独立生活卡片不承担正文任务的前置条件。

## 科学边界

- 表2的11模型×3指标×8基准共264个数值与同一v1来源逐格核对。
- 图5使用完整原始SVG，不重画曲线、不插值生成伪精确数据。来源：https://arxiv.org/html/2606.02373v1#S3.F5 。
- Q5的来源记录保留缺失中段、不同ID形式和核验结果未知；作者结果不冒充用户练习成绩。
- 教学虚构全文、BM25参数、字符预算与奖励算例明确标注；没有调用模型、训练或测量运行性能。
- 保留去重/回看消融的反例、Seal0的负差与论文正文/表格的数值差异。
