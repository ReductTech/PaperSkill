# Mind the Gap：CLIP 持续学习里的模态间隙（交互式教程）

交互式教程，讲解论文 *Mind the Gap: Preserving and Compensating for the Modality Gap in CLIP-Based Continual Learning*（ICCV 2025）。

- 作者：Linlan Huang, Xusheng Cao, Haori Lu, Yifan Meng, Fei Yang, Xialei Liu（南开大学 VCIP；NKIARI 深圳福田）
- 论文：<https://arxiv.org/abs/2507.09118>
- 代码：<https://github.com/linlany/MindtheGap>

## 这篇教程讲什么

CLIP 的图像特征与文本特征分处两个分离的锥体，中间那道缝就是**模态间隙**。用交叉熵微调会把它越推越大（遗忘），直接对齐又会改坏预训练知识。MG-CLIP 的做法是两步：先**保持**间隙（用负样本相似度的相对变化量决定何时停训），再**补偿**它的限制（在视觉空间另建一个不受间隙约束的分类器，推理时按 β 加权合分）。

教程用一个统一的生活比喻串起来：**录音棚里的两条轨**——一位录音师给大提琴录音，参考麦与近场麦之间有一个出厂就有的固定偏差；盯表停手对应保持，另开一路近场对应补偿。

## 数值与示意的分界

页面上的 Table 1–5 数值、Eq.(1)–(6) 的符号与结论均取自论文原文。以下三处是**教学示意**，不是论文数据，页面上已标注：

- 音分表读数与磁带波形：把“可测偏差”具象化，真实间隙是跨模态余弦相似度的整体水平；
- p2 的两条曲线：形状按 Fig.2a/2b 定性绘制，端点为 Table 5 的 CLIP / Base 行；
- p5 的奇异值柱：论文只给覆盖距离 d 与 Eq.(4) 的下界，没有逐奇异值数据。

论文的 Fig.1–5 均为矢量绘制，教程未直接引用原图，全部场景为按论文结构重绘。
