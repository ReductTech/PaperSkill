# VTW 交互式中文精读

论文：*Boosting Multimodal Large Language Models with Visual Tokens Withdrawal for Rapid Inference*（Zhihang Lin, Mingbao Lin, Luxi Lin, Rongrong Ji · **AAAI 2025**，Vol. 39 No. 5，pp. 5334–5342，2025-04-11，DOI [10.1609/aaai.v39i5.32567](https://doi.org/10.1609/aaai.v39i5.32567)）。

本项目基于 [PaperSkill](https://github.com/ReductTech/PaperSkill) 的 React + TypeScript + Vite 模板（`paper-skill/assets/react-template`，模板取自 commit `6d8f240`，2026-10-21）制作，页面文字为简体中文。**完整工程是本目录本身**；`dist/`（构建产物）与公网 Artifact 都只是构建结果。

## 运行

需要 Node.js 20 及以上。

```bash
npm ci            # 按 package-lock.json 安装依赖
npm run dev       # 本地预览 http://localhost:5173
npm run build     # tsc 类型检查 + vite 构建，产出 dist/
npm run preview   # 预览构建结果
```

PaperSkill 校验（在 PaperSkill 仓库根目录执行，路径换成本目录）：

```bash
node paper-skill/scripts/syntax-check.js <本目录> --require-parser
node paper-skill/scripts/validate-output.js <本目录>
```

调试参数：`?motion=reduce` 强制进入“减少动态效果”模式，与系统设置 `prefers-reduced-motion: reduce` 走同一条代码路径（页面根元素加 `.rm` 类、画布只画终态、不跑任何循环）。

## 与官方模板的差异

为满足“单页长滚动 + 手机端可用”的要求，以下改动超出了模板约定（模板约定只改 `tutorial.ts`、`paper.css`、`modules/*`、`public/*`）：

1. **`index.html`**：视口改为 `width=device-width, initial-scale=1, viewport-fit=cover`（处理刘海与底部安全区），补充 `theme-color`、`color-scheme`、`description`。
2. **`src/App.tsx`**：模板是 PPT 播放器（左侧缩略图目录 + 一页一屏 + 翻页按钮）；本工程改为单页长滚动，只保留顶部阅读进度条和右下角悬浮章节导航，没有侧边索引、没有上一章 / 下一章按钮；增加滚动入场与减少动态效果处理。
3. **`src/main.tsx`**：不再引入 `src/styles/components.css`——它为 PPT 播放器把 `html, body` 设为 `overflow: hidden`，会让长滚动页面无法滚动。`components.css` 文件本身保留未改动；`tokens.css` 仍然引入。
4. **`src/types.ts`**：只在文件末尾**追加**可选字段与新类型（利用 TypeScript 接口合并），模板原有字段全部保留；每章的 `scenes` 填空数组，封面 `hero.*.componentId` 指向本工程的封面舞台，模板组件仍能通过类型检查。
5. **`src/modules/registry.tsx`**：注册本工程的 26 个组件（`scaffold.js` 生成的空注册表被替换）。
6. **新增目录 / 文件**：`src/components/vtw/`、`src/ui/`、`src/lib/{hooks,stage,timeline,bus,flops,palette}.ts`、`src/data/tables.ts`。模板的 `src/components/*`、其余 `src/lib/*`、`tokens.css`、`components.css`、`presentation.css`、`vite.config.ts`、`tsconfig.json`、`package.json`（除 scaffold 注入的名称与标题）均未修改。
7. **视频推荐**：模板的 B 站组件保留在工程中但不渲染；`tutorial.ts` 没有 `bilibili` 字段，页面没有任何视频平台推荐。
8. **配色**：页面使用深色「潮退 · 月夜海岸」主题。token 类型：视觉 = 生物荧光青、系统 = 月银紫、指令 = 沙色、输出 = 珍珠白；状态语义固定为 绿 = 验证通过、琥珀 = 限制 / 证据边界、红 = 错误或失败（与模板 `contract.md` §5 的颜色角色不同，页面内部保持一致，图例见“资料与口径”一节）。
9. 运行时依赖仍只有 `react`、`react-dom`；无 CDN、外部字体、密钥或环境变量。

## 内容口径

- **编号与数字**以 AAAI 2025 正式版 PDF（9 页，页码 5334–5342）为第一依据。AAAI 正式发表页没有独立补充材料、正式版没有附录；arXiv v3 多出的附录（算法 1、表 7–9、图 9–12）在页面中一律注明“arXiv 附录”。
- **代码引用**固定到 [lzhxmu/VTW](https://github.com/lzhxmu/VTW/tree/b9cb1266c31f3be9b477e011f35e1c8597d36579) 的 commit `b9cb1266c31f3be9b477e011f35e1c8597d36579`，链接带行号。
- 页面用四种标记区分内容来源：**论文实测**、**代码事实**、**公式外推**（本页按论文公式或代码口径计算 / 反推）、**教学示意**（示意曲线、小模型、场景）。
- 主要核对结论（详见页面“核对”条）：
  - 层号相差一层：Eq. (5) 与图 2 字面是前 K−1 层带视觉 token；表 1 与官方代码（`layer_idx == k`，0 起计）是前 K 层。按 Eq. (1) 复算，表 2 的比例更接近代码口径。
  - 阈值不一致：论文 η = 0.003；代码按模型名设 7B 0.003、13B 0.0005、NeXT 0.0001；代码用 ≤ η，KL 方向为 KL(P_VTW ‖ P_原模型)，只比较第一个输出 token；候选层循环硬编码 `35:611`。
  - TFLOPs 复算：表 3（50.00% / 53.13%）与附录表 8（64% / 50%）精确一致；表 2 的 VTW 比例与本页相差 0.1–0.2 个百分点、FastV 相差 0.6–1.7 个百分点，标注“与本页复算不一致，原因未知”。本页推断表中 TFLOPs ≈ Eq. (1) × 2，论文未说明。
  - arXiv 附录表 9：7B VTW 子项相加 1848.52 ≠ 总分 1872.43；13B VTW 标 K=16 但数字与表 2 的 K=20 相同。
  - 相关论文：FastV 论文早于 VTW、全文没有 VTW；DivPrune 把 VTW 当基线时关闭校准、LLaVA-1.5 用 K=4、1.6 用 K=3（不是 VTW 原文推荐配置），其 §4.5 对基线延迟的解释与 VTW 官方代码不符。
- **统计边界**：论文为单次运行、无逐题结果和置信区间，页面只报告差值，小差值写“现有材料无法判断是否超出评测波动”；√(p(1−p)/n) 只作为单模型波动量级的教学示例（README 截图中 SQA 的 ±0.0102），不用于比较两个模型，也不用于 MME 总分、F1 等指标。
- 结论按“已证明 / 有解释但未证实 / 仍然未知”分级，每条写依据。

## 尚未验证

- 未在真机上测试，也未做真实触摸手势测试；手机端只在浏览器视口模拟下检查（v4：375×812、320×640 DOM 测量，第 1/3/5/10 章舞台 262–342 px、主要控件在一屏内（320×640 时第 10 章滑块低于屏幕底约 20 px），无横向溢出；v2：390 px 截图与 DOM 测量，最窄画布 330 px；320 px 在减少动态效果模式下做了 DOM 测量，最窄画布 260 px；均无横向溢出）。
- v2 检查期间内置浏览器面板一直处于隐藏状态，页面的 requestAnimationFrame、IntersectionObserver 与 CSS 过渡都不推进。因此：
  - 时间轴的播放逻辑（进入视口自动播放、暂停后进度不变、继续播放、封面循环）是在一个临时测试页里，用定时器代替 rAF 与 IntersectionObserver 验证的（测试页已删除，不在工程中）；动画在真实屏幕上的流畅度与帧率**没有实测**。
  - 各舞台的中间状态通过“暂停 + 拖动进度条”逐帧截图检查；CSS 入场与揭示动画只确认了计算样式的终态。
- v5 检查（模拟视口，均为 DOM 测量 + 截图）：第 5 章 K = 8 / 16 / 24 / 31 在“算账”阶段、转场中间（进度 0.86）与窗口 1000×700 下无文字叠影；320 / 390 宽度下整页无横向溢出（展开全部抽屉后检查），3 个长公式在公式框内横向滚动；7 个“先猜”模块逐题作答（含答错、答对、下一题、重新挑战）；第 5 章 K 滑杆与阶段按钮用真实键盘操作；问题入口跳转与底部收起；`?motion=reduce` 终态。
