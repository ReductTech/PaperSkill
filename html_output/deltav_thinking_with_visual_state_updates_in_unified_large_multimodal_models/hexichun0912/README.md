# DeltaV：让视觉推理只更新必要的变化

基于 **DeltaV: Thinking with Visual State Updates in Unified Large Multimodal Models** 的中文交互式论文教程，使用 PaperSkill 的 React + TypeScript + Vite 模板。

- [论文 v1](https://arxiv.org/html/2607.08434v1)
- [官方实现](https://github.com/Pengjie-W/DeltaV)
- [PaperSkill](https://github.com/ReductTech/PaperSkill)

## 本地运行

需要 Node.js 20.19+ 或 22.12+ 及 npm（也可使用 pnpm）。

```bash
npm install
npm run dev
```

正式构建：

```bash
npm run build
npm run preview
```

教程整理：何熹淳（XichunHe），AI 辅助制作。目录拼音：hexichun。

## 教学设计

十章从问题、表示、历史条件进入 TSIM 计算、预算校准、训练/推理分离、训练目标、结构、消融与结果。共 11 个主要交互模块，并在第 10 章补充统计口径核对交互，包含同步比较、热点选择、拖拽、参数调节、步骤推进和用户启动的实验展示。

“画板上的路线草图”是一种生活类比。所有画板、槽位和质量曲线示意都标明教学性质；本项目没有运行 DeltaV 模型，没有将教学模拟当作论文实测。

优先演示章节：1 → 3 → 4 → 5 → 6 → 10。研究方法细节可阅读 7–9 章。

## 工程结构

- `src/data/tutorial.ts`：全部章节内容。
- `src/modules/`：画板、参数、步骤、结构与实验交互。
- `src/styles/paper.css`：场景色彩变量，以及短屏目录的底部安全间距。
- 其余模板框架保持原样。

运行时仅依赖 React、React DOM；无需模型服务、CDN 或外部字体。文献链接由用户主动打开。
