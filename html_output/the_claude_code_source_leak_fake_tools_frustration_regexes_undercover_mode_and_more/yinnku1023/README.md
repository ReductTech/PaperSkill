## 内容与边界

围绕四条件激活、目录与工具注册、字段披露、关键词误判、请求校验、连续失败、数字证据、共同前缀与夜间权限展开。所有操作都是浏览器内确定性示例，不访问模型 API，不执行命令，不进行真实蒸馏、认证、库存读取、文件修改或发布。五位校验码不是密码学认证，前缀段数不是 token 或计费量，授权数量也不是安全评分。

统计页只转述作者引述的 2026-03-10 注释。缺少原始日志、总请求数和修复后记录，不能独立核验规模或计算节省率。KAIROS 为文章中的门控路径线索，不据此判断当前产品是否公开可用。

## 展示与运行

沿用使用者指定的 Sprouts 与 Yuhan 展示建议：一页一个问题、短句、统一字体与语义配色、较大字号、克制动画；详细讲解、操作、来源与过渡放入讲稿。固定画布遵循官方播放器，小屏使用缩放与平移。

运行 npm install、npm run dev；生产构建 npm run build。提交完整源码和锁文件，不提交 node_modules 或 dist。
