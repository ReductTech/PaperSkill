# FPN：用于目标检测的特征金字塔网络

基于论文 **Feature Pyramid Networks for Object Detection**（CVPR 2017）的中文交互式导读，共6章、13页。

论文原文：https://arxiv.org/abs/1612.03144

## 内容与交互

从远近行人的尺度问题出发，对比图像金字塔、单层深层特征、骨干多层特征与FPN，再解释自顶向下路径、横向连接和多层输出。

- 调整目标像素高度与骨干层，区分空间分辨率和语义表达。
- 切换四种多尺度表示方案，观察计算复用和语义增强的区别。
- 拖动叠合进度；在特征图中选点，与局部数组对应；编辑数值并比较横向连接开关。
- 计算RPN锚框IoU与RoI选层，区分两种任务规则。
- 对照论文消融实验与检测协议，查看尺度退化实验的适用边界。

## 运行

```bash
npm install
npm run dev
npm run build
npm run preview
```

项目使用React、TypeScript和Vite，保留PaperSkill固定画布与翻页框架。通过目录或方向键翻页；输入控件优先处理自身按键。手机支持画布缩放。提交版隐藏讲稿入口。

## 来源与示意边界

街景、行人、特征网格及结构图由本项目以SVG和代码绘制，没有使用论文图片、第三方照片、外部视频或论文PDF。页面截图为本项目运行画面的缩略图。

FPN方法依据论文第3节及图1—3；RPN与RoI依据第4节；实验数字依据表1—3和表6。页面中的教学数组、颜色与轮廓是手工构造的示意，不是网络实测激活，也不能从中推算检测精度。具体数值与对应协议保留在源码数据中。

末页尺度退化结果来自作者独立完成的PennFudanPed检测实验：固定COCO预训练的Faster R-CNN MobileNetV3-FPN，对170张图像进行配对尺度变换，无训练或微调。这不是移除FPN的消融实验，不能据此判断FPN的独立贡献。项目不包含数据集图像或本地学习聊天记录。

本项目基于PaperSkill提供的React + TypeScript运行框架制作，并结合作者学习讨论调整讲解、交互及内容组织。
