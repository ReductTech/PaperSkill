# FPN 交互式论文导读

论文：**Feature Pyramid Networks for Object Detection**，Tsung-Yi Lin 等，CVPR 2017。

导读整理：Zijie Wang（GitHub：mathlover0728）。本版在用户提供的 FPN 单文件导读上修订，恢复为可维护的 React 项目，采用前次 SCTransNet 导读的章节阅读版式。全部教学图由 SVG 绘制。

## 打开与编辑

- **源码预览：** 安装 Node.js 后，在本目录运行 `npm ci`，再运行 `npm run dev -- --host 127.0.0.1 --port 5191`。
- **构建：** `npm run build`；构建产物在 `dist/`。
- **更新单文件：** 构建成功后运行 `npm run export:html`。
- 本机 `127.0.0.1` 地址只能在运行服务器的电脑上使用。手机可接收 `打开导读.html` 后用支持本地 HTML 的浏览器打开；不能把电脑的回环地址当成手机访问地址。

## 内容结构

共 6 章、11 个主要交互模块：

1. 多尺度难题：比较四类多尺度方案。
2. 构建金字塔：C/M/P 信息流、尺寸推算、合成融合矩阵。
3. RPN 与召回：锚框匹配、表 1 消融。
4. RoI 与检测：原式、层级边界、表 2/3 比较。
5. 基准与分割提案：表 4/5 的配置区分、表 6 的 AR 与时延。
6. 关联与证据边界：后续文献入口及六个核对条目。

左右箭头可在非控件区域切换章节；表单、图内可操作对象保留自己的键盘行为。上下方向键用于正常滚动。手机使用“目录”按钮；较宽的图示只在模块内部横向滚动。章节链接支持 `?chapter=0` 至 `?chapter=6`。

手机结果图使用可点选的条形卡片，数值、实验条件和说明与桌面共用数据；复杂结构图保留模块内滑动。手机与平板目录使用抽屉，Escape 可关闭。封面对比动画可暂停与重播，结构讲解可逐层推进，RPN 条形比较可手动启动；动画不表示模型运行时间。

## 论文证据与教学边界

统一依据 [CVF CVPR 2017 正式 PDF](https://openaccess.thecvf.com/content_cvpr_2017/papers/Lin_Feature_Pyramid_Networks_CVPR_2017_paper.pdf)，各模块提供节、表、PDF 页码及实验条件。

- `M` 是导读增加的融合中间量记号，用于区分递归通路与经 3×3 输出的 `P`。
- RoI 原式使用 `floor(4 + log2(sqrt(w*h)/224))`；有限层裁至 P2–P5 在导读中单独标为实现处理。
- 36.2 AP 为表 4 的最终 ResNet-101 test-dev 配置；0.165/0.19 秒为共享特征的 ResNet-50/101、M40 系统计时，不能拼为同一实验结果。
- 表 6 为无类别掩膜提案 AR，不是 Mask R-CNN 的类别实例分割 AP。
- 城市场景、热力图和几何操作都是教学示意。该网页没有训练或评估检测模型，网页测试不等于模型复现。
- 后续文献关系是阅读组织，分别链接 YOLOX、ByteTrack、ACM 原文，不声称 FPN 原文验证了它们。

## 主要文件

- `src/data/tutorial.ts`：章节正文、公式说明、来源。
- `src/modules/recovered.jsx`：从用户导读恢复并修订的交互；React 通过正常依赖导入，无旧放映壳或内嵌供应商运行时。
- `src/modules/registry.tsx`：显式注册交互与章节类比。
- `src/styles/fpn.css`、`guide.css`：FPN 响应式布局和来源标注。

公开投稿源项目；网页由 AI 辅助修改和核验。原文数据与教学计算分别标记，未运行 FPN 检测模型。使用者可继续对照原文检验解释与实验边界。
