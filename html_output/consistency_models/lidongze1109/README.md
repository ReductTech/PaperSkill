# 一致性模型交互式教程

基于 Yang Song、Prafulla Dhariwal、Mark Chen、Ilya Sutskever 的论文 **Consistency Models**（ICML 2023 / PMLR 202）。内容核对版本：[arXiv:2303.01469v2，2023-05-31](https://arxiv.org/abs/2303.01469v2)。页码均为该PDF印刷页码。

## 运行与构建

需要 Node.js 与 npm。在本项目目录执行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 18473
npm run build
npm run preview -- --host 127.0.0.1 --port 18474
```

开发预览：http://127.0.0.1:18473/ 。构建结果预览：http://127.0.0.1:18474/ 。

## 内容与证据

共10章、12个主动交互模块，覆盖概率流、边界参数化、CD/CT训练、EMA、采样、网络结构、零样本编辑与实验结果。每个模块标注原论文章节、公式或表格位置。

- 表格中的28条FID/NFE记录逐项对应v2第8页表1—2。附录部分图注存在不同数值，本教程以主表为准。PD使用ℓ2，CD/CT使用LPIPS；不同数据集分别比较。NFE不是实测运行时间，FID不是单张图像评分。
- 概率流模块是根据高斯密度自行推导的可解例子，不是论文实验；其他路径、标量EMA、8×8掩码图也是教学示意，不执行真实图像生成。
- CD扩散教师与EMA目标网络分开解释；CT与CD的联系受定理2假设限制。编辑实验范围为论文Bedroom CD样例，附录D使用40个采样时间点，不能据此声称一步编辑。
- Canvas插图由教程绘制；项目不包含原论文PDF或复制的论文图片。B站视频链接是补充学习材料，论文事实以原文为准。

## 操作

左侧目录切换章节；滑块、按钮和可聚焦画布提供操作及文字反馈。演示尊重系统“减少动态效果”设置。页面沿用PaperSkill固定画布模板，窄屏整体缩放并可纵向滚动。

## 工程与提交

React + TypeScript + Vite项目，使用paper-skill模板。论文内容在`src/data/tutorial.ts`，交互在`src/modules/`，配色在`src/styles/paper.css`；保留模板框架。

提交应保留完整项目源文件及依赖锁文件，不提交`node_modules/`、`dist/`、原论文PDF、临时缓存或本地检查截图。上述构建目录已在`.gitignore`排除。

本轮复核包括原文对照、语法及结构验证、生产构建、桌面全部章节交互、窄屏检查、动画暂停/恢复，以及高斯例子的端点一致性验证。正式导入PaperSkill仓库时，仍需填写作者认可的公开署名等元信息，并运行仓库自己的导入与PR预检；本项目构建成功不替代这些检查。
