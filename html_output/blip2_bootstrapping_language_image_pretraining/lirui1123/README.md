# BLIP-2 中文交互教程

启动：npm install，然后 npm run dev -- --host 127.0.0.1 --port 5173。生产构建：npm run build。

## 本轮：精简文字与后七页机制重构

- 全部正文页的导读压缩为一句，重复解释合并；详细推导、出处和教学边界放到讲稿。
- FC：先看到维度不匹配，再加入共享矩阵，用两条查询与显式目标校准，区分形状适配和语义适配。
- OPT/FlanT5：按词选预测位置，显示可读条件、遮蔽位置、前后缀与损失位置。
- 两阶段：独立切换提取相关信息与输入坐标适配，检验两步分别缺失的后果。
- 零样本VQA：解释0–100分及部分记分，固定同协议的原始值，突出+8.7分和−4.7分所支持的结论。
- 描述/检索/消融：每次聚焦一个科学问题，给出指标含义、比较协议、真实差值和一句结论。
- 监督VQA：问题修正查询→相关区域权重改变；用标注答案损失说明训练信号，冻结LLM权重。
- 事实可靠性：同图核对支持、矛盾、未知三类断言，并逐句按证据修订。
