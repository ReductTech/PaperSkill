# RABBIT中文交互式论文导读

7章、13页（含封面），10个可操作模块。

双击 `启动导读.cmd`，或运行：

```powershell
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1 --port 5174
```

浏览器打开 http://127.0.0.1:5174 。构建：`npm.cmd run build`。支持目录、讲稿、键盘翻页与移动端缩放。

原文和关键结论见 SOURCES.md，验证见 VALIDATION.md。图示、融合分数、温差判定、路点覆盖及接触几何都是教学简化，不是真实CMX推理、力控制仿真或临床建议。实验数据固定来自论文表1及第4节；仅涉及小规模前臂研究。
