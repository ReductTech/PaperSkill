# SeeSR：面向语义感知的真实世界图像超分辨率 · 交互式教程

基于论文 **SeeSR: Towards Semantics-Aware Real-World Image Super-Resolution**（CVPR 2024，
Rongyuan Wu, Tao Yang, Lingchen Sun, Zhengqiang Zhang, Shuai Li, Lei Zhang），由 **paper-skill**
生成的完整 React + TypeScript + Vite 交互式教学项目。

## 本地运行

```bash
npm install
npm run dev       # 开发预览 http://localhost:5173
npm run build     # 产出 dist/ 静态站点
npm run preview   # 预览构建结果
```

## 这讲怎么讲

统一的生活类比是**古画修复工作室**：修复一幅糊掉的残卷时，第一步不是落笔，而是先认定"画的是什么"。
把这一判断写成清单，就成了论文里的硬提示（标签文本）与软提示（表示嵌入）；认定错了，补出来的就不是同一件东西。

| 章节 | 讲什么 | 可操作的核心机制 |
| --- | --- | --- |
| 第一章 · 语义先于细节 | 退化如何把"这是什么"变成多选题；分类式/描述式/标签式提示各把残卷带向哪里 | 拖退化强度看两个候选同时成立；点选五种提示词看补绘对象改变 |
| 第二章 · 退化感知提示提取器 | DAPE 用干净摹本的两个锚点做对齐（式 1）；退化怎样改写标签排序；阈值与软提示的补偿 | 调 λ 与训练进度看 L_r / λL_l 分解；切换原始标签模型与 DAPE；拖阈值看命中/误检 |
| 第三章 · 双提示驱动受控扩散模型 | 文本经 TCA、表示经 RCA（位于 TCA 之后）、图像经 ControlNet 进入冻结 Unet；LRE 修正采样起点 | 开关三条分支看活跃条件与结果判断；拖"起点中来自残卷的比例"看天空虚假笔触 |
| 第四章 · 证据 | 表 2 的 FID/CLIPIQA/MUSIQ；表 3 的下游语义指标；图 4 定性结果与表 4 用户研究 | 切换数据集与指标；点选定性对比的一列 |
| 第五章 · 边界与取舍 | 标签错一个字会画错什么；保真与感知的交换、适用条件 | 增删标签清单看补绘对象；点散点读该方法的 PSNR/CLIPIQA |

## 关于示意与证据

- 页面中的残卷绘画、标签置信度曲线、损失分解、笔触数量都是**讲解用的示意模型**，用于复现论文的因果趋势，
  不是论文报告的数据；页面上已标注"示意"。
- 实测数字全部取自论文表格：表 2（p.6）、表 3（p.8）、表 4（p.8），并保留原协议、单位与指标方向。
- 两处论文原图为本地裁剪：`public/images/panel-tag-lr.png`（图 1(d)）与 `public/images/qual-*.png`（图 4 第一例放大行）。
  出处与类比边界写在每页的演讲者备注中（"讲稿"按钮）。

## PPT 演示模式

每章包含多张独立幻灯片，每页固定为 1600×900。顶部翻页，左侧预览选页，"讲稿"打开演讲者备注，
"放映"进入全屏。方向键翻页不会抢占输入控件；手机保持原有排版，支持双指缩放、放大后拖动以及缩放复位。
`?capture=1&slide=<页面 ID>` 可在 1600×900 窗口中单独捕获页面。
