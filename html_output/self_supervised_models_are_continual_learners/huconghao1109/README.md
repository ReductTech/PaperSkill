# 自监督模型本身就是持续学习者 · 交互式教程

基于论文 *Self-Supervised Models are Continual Learners*（CaSSLe, CVPR 2022, arXiv:2112.04215），用 paper-skill 生成的 React + TypeScript + Vite 项目。

## 这套教程讲什么

用「乐队换琴 · 移调合奏」一条线索贯穿十章：旧录音是冻结编码器给出的过去表征，新琴是当前编码器，移调夹是预测头 g，同一支音叉是复用的同一个自监督损失。

| 章 | 主题 | 主要交互 |
| --- | --- | --- |
| §1 | 顺序到来的数据为什么会走音 | 按住琴弦往下拨，每拨一次推进一个任务 |
| §2 | 没有标签时 SSL 靠什么校准 | 拖动裁剪框，看两个视图被拉近 |
| §3 | 不要求不变，只要求能翻译回去 | 拖动分割线，左右擦开对比 |
| §4 | 冻结一份副本，继续训练当前编码器 | 四步查看梯度路径 |
| §5 | 同一支音叉，不需要第二支 | 转动旋钮，松手吸附到四档之一 |
| §6 | 一步训练怎么走完 | 拖动时间轴看五步 + 交换视图消融 |
| §7 | 三种「换新」不一样 | 把「新类别/新样本/新风格」拖到对应轨道 |
| §8 | 一套框架，四种校音法 | 点击架构节点，切换四类损失 |
| §9 | 长时间演出还准不准 | 拆部件消融 + 拖拽任务序列长度 |
| §10 | 正式回放：赢了什么，还没解决什么 | 同协议结果赛跑 + 三条限制与一个例外 |

共 10 章、14 个主动交互模块、10 段类比动画。操作方式覆盖拨弦、拖裁剪框、拖分割线、转旋钮、拖时间轴、拖放卡片、点击热点、步骤推进与结果赛跑，每章至少一个可操作模块，第六、八、九、十章各有双模块。

## 本地运行

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # 产出 dist/ 静态站点
npm run preview   # 预览构建结果
```

依赖已在当前目录安装过，通常直接 `npm run dev` 即可。交付时保留整个项目目录，不要只复制 `index.html` 或 `dist/`。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `src/data/tutorial.ts` | 全部章节文案、模块描述、公式与符号 |
| `src/styles/paper.css` | 场景配色覆盖 + 连续滚动布局 |
| `src/modules/scene.ts` | 共享 Canvas 绘图套件与语义色 |
| `src/modules/*.tsx` | 各章交互组件，统一在 `registry.tsx` 注册 |
| `src/App.tsx` | 连续滚动外壳、侧边目录、错误边界 |
| `src/components/*` | 展示组件（章节桥、类比卡、模块框、公式、要点） |
| `public/images/*` | 可选论文原图（本教程未使用，全部为手绘 Canvas） |

## 配色语义

`--blue` 当前状态/引导，`--green` 本文方法/成功，`--red` 失败/旧方法，`--orange` 用户控制的强调，`--purple` 辅助机制。所有 Canvas 与页面使用同一套语义，红不表示成功，绿不表示失败。
