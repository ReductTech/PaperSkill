# 故事架构

一句话：让每张图选择值得做的处理，以训练时检测反馈学习策略，在推理时按阶段预算逐步执行。

问题 → 决策 → 工具 → 动作 → 策略 → 反馈 → 成本 → 执行 → 学习 → 对照 → 证据 → 结果 → 路径 → 原图 → 专题 → 边界 → 复习 → Final。
