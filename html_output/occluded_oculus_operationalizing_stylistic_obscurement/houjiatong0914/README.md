## 项目介绍

### 一句话

论文在问：**在公开、不加密的匿名写作场景里，翻译、混淆、模仿、注入这四个攻击模块中，哪一个最能击穿作者归属系统？单点是否足够？** 本教程把这个问题的提出、方法、实验与结论，拆成 11 页可以点击、切换、步进、拖拽的中文交互页面。

### 论文讲了什么（教程呈现的核心）

- 作者归属把写作风格变成可计算的统计特征（功能词频率、字符级与词级 n-gram、词性分布、词汇丰富度），再由分类器把文本归给最像的候选人。
- TraceTarnish 攻击由四个模块组成：**翻译（T）、混淆（O）、模仿（IM）、注入（IN）**；注入内部又分**零宽字符（LI）、同形字（DI）、拼写差异（SI）**三种。
- 论文用 R 语言的 `stylo` 包（`classify()`、`imposters()`、`crossv()` 等）做了 **15 种非空组合的消融实验**：训练集为 Gilmore / Hughes / May 三位密码朋克作者，测试文本是 Hughes 的 *A Cypherpunk's Manifesto*。
- 结论：**只有注入能造成误归属**（Hughes 的文本被改判为 May）；移除注入后，其余组合都无法造成误判——注入既**必要**又**充分**。
- 论文同时给出两层排序口径（正文：注入 > 模仿 > 混淆 > 翻译；附录全文实验：注入 > 模仿 > 翻译 > 混淆）、可行的防御方式，以及作者自陈的边界与伦理代价。

### 教程规模

| 项目 | 数量 |

| 页面 | 11 页（封面 + 10 章：基础 4 / 进阶 3 / 训练 3） |

## 快速开始 / 打开交互式网页

### 环境要求

- Node.js **18 或更高**（推荐 20 / 22 LTS）
- npm 9 或更高

### 安装

```bash
git clone <本仓库地址>
cd occluded-oculus_output
npm install
```

### 方式一：开发模式（改代码即时生效，最常用）

```bash
npm run dev
```

终端会打印本地地址，通常是 **http://localhost:5173/** ，用浏览器打开即可。

### 方式二：预览构建产物（最接近上线效果）

```bash
npm run build     # 产出 dist/ 静态文件
npm run preview   # 本地预览构建结果
```

默认地址为 **http://localhost:4173/** 。

### 方式三：部署到静态托管

`npm run build` 生成的 `dist/` 是纯静态站点，可直接部署到 GitHub Pages、Netlify、Vercel、Cloudflare Pages 等平台。

如果部署在**子路径**（例如 `https://用户名.github.io/仓库名/`），需要先在 `vite.config.ts` 中设置：

```ts
export default defineConfig({
  base: '/仓库名/',
  // ...
});
```

### 手机 / 平板同屏查看

```bash
npm run dev -- --host
```

终端会打印形如 `http://192.168.x.x:5173/` 的地址，手机连接同一个 Wi-Fi 打开即可。

### 页面操作方式

- 底部「上一章 / 下一章」按钮翻页，或使用键盘 **← →**（**↑ ↓** 亦可）
- 左上角「目录」按钮展开章节列表，可直达任意一页
- 每个模块都是**一次操作对应一处反馈**：点击、切换、步进或拖拽后，图形与说明文字会立刻更新

### 常见问题

| 现象 | 原因与解决 |
| ---- | ---------- |
| 双击 `index.html` 打开是**白屏** | 浏览器对 `file://` 下的 ES Module 有同源限制，必须通过 HTTP 访问；请使用上面的 `npm run dev` 或 `npm run preview` |
| 端口被占用 | 换端口启动：`npm run dev -- --port 5174` |
| 首次运行提示找不到依赖 | 先在项目根目录执行 `npm install` |

## paper-skill 使用说明

本项目由 **paper-skill** 生成。它是一个 Codex 技能：输入一篇论文，输出一个自包含的中文交互教程项目文件夹。

### 前置条件

- 在支持 Codex 技能的环境中安装 `paper-skill`（技能文件位于 `~/.codex/skills/paper-skill/SKILL.md`）
- 本机可用的 Node.js 与 npm

### 调用方式

在 Codex 中用自然语言点名技能并附上论文，例如：

```
$paper-skill 把这篇论文做成中文交互教程：https://arxiv.org/abs/2607.24411
```

论文可以是 **PDF 文件、LaTeX 源码、纯文本、论文链接，或足够详细的文字描述**。

### 技能内部做什么（两阶段，一次调用内连续完成）

1. **阶段一：把论文变成「论文专属子技能」**
   - 先将论文解析为一份经过校验的缓存记录（任务级临时目录，用完即弃）
   - 再据此生成一个只服务于这篇论文的子技能，写入章节脚本、交互设计、配色与 Canvas 规范
2. **阶段二：立即执行该子技能，产出并校验项目**
   - 脚手架生成 React + TypeScript + Vite 工程
   - 按章节生成内容与交互组件，组装数据与样式，运行校验
   - 删除任务级临时目录，**只交付 `<论文短名>_output/` 一个文件夹**

本仓库的 `occluded-oculus_output/` 正是该约定的产物。

### 可用环境变量

| 变量 | 作用 |
| ---- | ---- |
| `PAPER_SKILL_DEBUG=true` | 保留中间生成的「论文专属子技能」，便于查看生成规则与章节脚本（默认会删除） |

### 产出约定（了解这些有助于二次修改）

- **正文全中文**：讲解、标签、反馈文案均为简体中文
- **只改约定内的文件**：论文专属内容集中在 `src/data/tutorial.ts`、`src/modules/*.tsx`、`src/styles/paper.css`、`public/`
- **框架文件不动**：`src/components/*`、`src/lib/*`、`src/styles/tokens.css`、`src/styles/components.css` 属于模板框架
- **数值与配色统一取值**：硬性数值与配色语义由子技能的 `contract.md` 统一，页面与脚本从同一份契约读取，避免出现两套数字

## 设计约定

- **配色语义固定**：`--blue` 指导 / 当前状态，`--green` 成功 / 本文方法，`--red` 失败 / 传统方法，`--orange` 用户强调，`--purple` 辅助机制。
- **统一的视觉母题**：全部图形使用「信笺 + 钢笔 + 印章」的纸面语言，避免每章各画一套风格。
- **一次操作、一处反馈**：每个模块只有一个主导操作，操作后同时更新图形与说明文字。
- **可访问性**：键盘焦点可见、支持 `prefers-reduced-motion`、移动端触控目标不小于 44px。

## 已知限制

- 移动端为把整张图放进屏幕，模块画布会缩到约 0.27 倍，**画布内的小字难以辨认**；同样的信息会在画布下方的详情面板中以正常字号给出。
- 教程是对论文的**教学性重构**，覆盖主要脉络（消融实验与注入机制），数学细节与全部附录图表做了取舍。
- 图表为按论文数据**重绘**的示意图，形制与论文原图不完全一致，严谨引用请以论文为准。
