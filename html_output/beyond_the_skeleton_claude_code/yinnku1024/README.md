# 骨架之外的灵魂：Claude Code 源码阅读笔记 · 交互式教程

基于一篇微信公众号文章的中文交互式讲解，13 页幻灯片、5 个章节。
教程用"体检中心"的场景（分诊、复查、睡眠监测、药房、安检、值班室）解释文章里十二个
"读完源码之后停下来想了一会儿"的设计，全部用浏览器内的确定性规则演示。

## 教学主张

文章列了十二个瞬间，教程把它们收成三个科室、两个关口、一条控制通道：

> 骨架回答"怎么搭"，这篇问"为什么这么想"；真正能带走的是判断，不是实现。

| 位置 | 文章里的落点 | 这一页的结论 |
| --- | --- | --- |
| 复查科 | verificationAgent 的反合理化清单 | 阅读只能给 PARTIAL |
| 睡眠科 | autoDream 三重门控 | 反思不适合实时做 |
| 药房 | `SYSTEM_PROMPT_DYNAMIC_BOUNDARY` | 一条分界线一天省五位数 |
| 安检科 | yoloClassifier 两阶段 | 安全是管道，不是开关 |
| 处方科 | 十几个函数的提示词组装 | 教模型克制，而不是教写码 |
| 值班室 | KAIROS 的 tick / Sleep / SendUserMessage | 主动性是知道何时闭嘴 |
| 监控室 | 遥测与远程配置优先级 | 一条从云端到终端的通道 |
| 控制台 | 320+ 环境变量 | 真正影响行为的是少数 |

## 本地运行

```bash
npm install
npm run dev       # 开发预览 http://localhost:5173
npm run build     # 产出 dist/ 静态站点
npm run preview   # 预览构建结果
```

## 演示修订

按 [新芽幻灯片指南](https://grokcv.site/sprouts/guide/) 与
[张雨函的分享建议](https://grokcv.site/sprouts/yuhan/) 组织：

- **一页一观点**：13 页全部用结论式标题，副标题是一个问题；出处、推断与边界放进讲稿。
- **字号与栅格**：正文 30px、局部标题 36px、焦点数字 46px（1600×900 固定画布，约合 22.5pt；
  全屏播放按视口整体放大）；字号只有三档，位置全篇统一。
- **配色克制**：白底 + 薄荷灰，语义色只有三种——蓝=当前、绿=通过、红=风险，橙色只标"可调量"。
- **开篇信息完整**：第二页写全载体、对象版本、体量、抓取状态、署名与日期缺失，并区分
  "作者亲读 / 已有分析 / 本文解释"三层。
- **图表先结论**：每个交互都先给一句判定，再给数字；安全页明确标注"教学复现，不是真实分类器"。
- **动画节制**：只有封面两段同步演示，其余点击即时反馈，无循环动画。
- **批判性收尾**：固定有"信息与动机"和"收束"两页，并明确 320 个变量里大多数不该碰。
- **时间分配**：建议 16–18 分钟；讲稿逐页给出建议时长、操作顺序、停顿点与过渡句。
