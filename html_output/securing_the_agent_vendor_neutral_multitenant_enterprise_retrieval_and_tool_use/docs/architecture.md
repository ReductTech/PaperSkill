# Runtime Architecture

本项目是论文 *Securing the Agent: Vendor-Neutral, Multitenant Enterprise Retrieval and Tool Use* 的 React + TypeScript 交互式教程。页面以现场讲解为主：动画解释因果机制，论文数值与教学示意严格分离。

## 叙事架构

七章内容围绕两条互补路径组织：

```text
策略感知摄取 -> 两级检索门控 -> 授权上下文 -> Shared Inference
                                                   +
客户端请求 -> 服务端编排 -> 工具逐次授权 -> 租户状态 -> 响应
```

前三层限定模型能看到什么，服务端控制路径限定 Agent 能怎样行动。检索门控提供隔离安全；服务端编排把安全步骤放入客户端不可绕过的执行边界。

## 单向渲染流

每个动画模块遵守同一数据流：

```text
timeline progress / direct input / centralized evidence
                         |
                         v
               deriveScene(progress, inputs)
                         |
                         v
                     SceneModel
                  /       |       \
             Canvas    readout   feedback / ARIA
```

`deriveScene` 是纯函数，不绘图、不调度帧、不修改 React 状态。Canvas、数值、反馈与无障碍描述读取同一个模型，避免图和文字相互矛盾。

## 时间轴归属

应用不存在全局进度。`useTimeline` 默认为每个模块创建独立 store；只有描述同一个因果事件的可见视图才使用 `TimelineGroup`。

| 作用域 | 同步视图 | 共享原因 |
| --- | --- | --- |
| Hero | 传统 RAG / 论文方法 | 同一个 Finance 查询的同步对照 |
| `5.2` | 当前攻击的客户端 / 服务端对照 | 同一攻击共享时间刻度，但按各自受控路径运动 |

`3.2` 的候选槽、Recall 曲线、读数和反馈来自一个模块模型，但不会与别的章节共享进度。它的 6.2 秒主时间轴负责完整讲解，人工切换过滤位置时使用独立 700 ms 局部时间轴，且不改变当前语料规模。`4.1` Shared Inference、`5.1` 工具/状态和 `5.2` 编排绕过即使相邻，也各自拥有独立时间源。`4.1` 默认 `1.5×`，`6.1` 默认 `0.5×`，其余完整动画默认 `1×`；这只改变初始播放倍率，不改变归一化场景进度或拖动精度。

## 关键场景

### Hero

Hero 的两栏共享查询、排名、授权范围、选择和上下文五个阶段。论文栏中的 Legal 只作为“忽略授权时会排第一”的虚线反事实参照，绝不会移动到上下文；Finance 从授权集合进入上下文。具体的后过滤与谓词下推实现留到 Chapter 3。

### 两级检索门控

`3.1` 不再使用等价节点组成的横向流水线。左侧资源决策室让用户属性与资源属性汇入搜索前的 ABAC 闸门；资源级 `DENY` 会关闭闸门并锁住整个下游区域，因此不会显示搜索结果、chunk 决策、上下文或推理。资源级 `PERMIT` 后，右侧搜索池依次返回四个 chunk，每个 chunk 经过独立筛选槽，并分别进入红色拒绝区或绿色授权上下文。所有者匹配保留 `4/4`，团队匹配保留 `2/4`，默认拒绝保留 `0/4`。

### 规模效应与谓词位置

`3.2` 保留 25 个稳定的 `5× over-fetch` 候选位置和 5 个稳定结果位置。候选租户混合、过滤位置、图表游标、统计和反馈由同一语料/模式状态派生；拖动时只连续改变 token 的颜色、透明度与局部位移，不增删位置。左侧明确标为机制示意，精确证据只落在右侧四个实心锚点。

授权过滤条按三个互斥阶段移动：先在候选池下方收缩为 `P`，再沿网格右侧空白通道上移，最后在候选池上方展开。该轨迹不进入候选 token 的包围盒。绿色谓词下推证据出现时，红色后过滤曲线仍保留为对照；二者分别维护自己的精确/插值标记，且不会推造统一的谓词下推时延。

为满足桌面投屏可读性，3.2 保持 `560x316` 逻辑坐标，但独立显示到最大 `820px` 宽；`useCanvasScene` 根据 CSS 尺寸同步提高后备分辨率。这样最小 `8px` 逻辑标签实际约为 `11.7px`，主要 `11px` 标题约为 `16.1px`。

### Shared Inference

`4.1` 使用独立 5.4 秒时间轴并默认以 `1.5×` 播放。三份上下文始终携带自己的 owner，经策略门后可以收束到一个共享模型端点。教学拓扑从 `O(N × M)` 变为 `O(M)`，但 A3 明确排除模型参数记忆隔离。

4.1 的策略门、上下文信封和模型端点共享 `SHARED_INFERENCE_LAYOUT` 几何合同。信封先在门右侧 `x=260..270` 的安全区淡入，再移动到 `x=378`；门后最小间距为 7px，模型前间距为 15px。共享终态使用 `y=104/132/160` 三个独立输入槽位，26px 高的信封之间保留 2px 空隙，因此“共享端点”不会在视觉上误画成“混合上下文”。三租户模型先完成淡出，共享模型随后淡入，模型标签不会交叉叠印。

### Agent 风险

`5.1` 使用本地 850 ms 步进，把本轮 Finance 请求、授权上下文、首次推理、工具前校验和工具结果画在上半区；最终一步先沿橙色曲线把工具结果写入状态保险柜，再沿绿色或红色曲线把历史回流到下一轮 Finance 上下文。共享状态会带回 Legal 旧结果，租户状态则把 Legal 结果留在独立分区。Canvas 保持 `560x292` 逻辑坐标并独立显示到 820px，最小 7.5px 逻辑标签约为 11px。`5.2` 使用独立 5.2 秒时间轴：跳过检索时客户端曲线完全避开 ABAC 门控，未授权工具时 `tool_call` 在客户端直达工具而在服务端转入逐次授权，旧上下文场景则用 Legal / Finance 状态卡片展示污染与租户分区。三个攻击各有阶段配置，只有当前攻击的左右两栏共享进度。

### 架构请求闭环

`6.1` 使用独立 7 秒时间轴并默认以 `0.5×` 播放，把 Figure 1、Figure 2 与 Table 1 收束为一次 Finance 请求。七个连续阶段依次展示离线策略感知摄取、服务端接管、ABAC 检索、授权上下文装配、共享推理与逐次工具授权、Finance-only 状态写入、输出检查与响应返回。离线摄取不在查询路径上；Legal chunk 在门控处停止，始终不会进入授权上下文；工具必须在逐次授权后执行；状态写入只抵达 Finance 分区。

场景由 `deriveArchitectureScene(progress)` 纯计算，固定节点和可信服务端边界从首帧可见，移动 token 使用连续路径插值，因此正向播放与反向拖动不会残留后续状态。客户端直连推理的旁路尝试在边界处终止。教学结论保持为：数据路径决定模型能看到什么，控制路径决定 Agent 能做什么，服务端编排让安全步骤不可绕过。OGX 的稳定 API 与可替换提供者只保留在章节文字和 takeaways，不混进这条请求动画。

### 三问证据

`7.1` 保留一个本地 900 ms 的问题切换时间源，但三种问题使用不同的视觉语法：

- 安全：带横轴“未门控/门控”的 A/B/C/D 2×2 矩阵，横向箭头强调门控把 CTLR/AVR 与提示注入泄漏压到零；服务端行表达不可绕过的执行保证。
- 质量：Precision@5 和 MRR 使用 0–1 哑铃轨道展示过滤前到门控后的移动；下方用对数规模折线展示 §3 后过滤 Recall@5 从 `1.000` 降到 `0.002`。
- 代价：约 19 ms、约 3 s 和并发 25 QPS 使用三个独立量纲块；吞吐块明确列出 A/B/C/D 的对应值，不共享定量轴。

毫秒、秒与 QPS 不共享定量轴。

## 证据边界

`src/modules/evidence/paperEvidence.ts` 是论文测量值的单一来源。`src/modules/evidence/scenarios.ts` 保存 Finance、Engineering、Legal 的教学输入；这些数据带 `illustrative: true`，不是实验记录。

Chapter 3 使用四个精确锚点和对数空间教学插值。锚点为实心点，插值为虚线并显示 `约`。可见协议固定为 `sqlite-vec · 5× over-fetch · 实心点为实测`。谓词下推时延保持空缺，不推造统一数字。

论文保证依赖 A1-A4，并排除模型既有参数记忆、侧信道和服务端被攻破的情况。约 `19 ms` 只适用于评估中的门控搜索路径；约 `3 s` 只适用于评估中的非流式 Responses API 工具往返。

## 生命周期与可访问性

`useCanvasScene` 负责 HiDPI 后备分辨率、resize 重绘、首帧 `is-ready`、离屏暂停和 2D context 失败回退。完整动画控制条支持播放、暂停、重播、`0.001` 连续拖动和 `0.5x/1x/1.5x` 速率。

直接操作会暂停当前模块且不自动恢复。`prefers-reduced-motion` 下，完整动画依次访问有意义的阶段边界并抵达相同结论。七章类比图按当前章节直接映射，不保留旧十章编号。Chapter 7 后的扩展视频位于默认关闭的 `<details>`，不参与主叙事。
