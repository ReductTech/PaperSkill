# LabVLA: Grounding Vision-Language-Action Models in Scientific Laboratories

中文交互式论文导读，贡献者：方豫馨（GitHub：yx-1021）。

论文来源：[LabVLA](https://arxiv.org/abs/2606.13578)。方法与讨论参照论文第二、三、八节。

## 运行

需要 Node.js 20 或更新版本。在项目目录运行：

```sh
npm install
npm run dev
```

运行 `npm run build` 完成 TypeScript 检查并生成生产版本，`npm run preview` 预览构建结果。

## 页面与交互

- 封面：机械臂抓取烧杯、放上平台、松开后撤回。
- 研究问题：领域数据与采集、机器人形态差异、书面流程到连续操作。
- RoboGenesis：环境可达性操作、资产与场景构建、工作流生成与审阅、执行中的结构化标注。
- 策略预训练：两阶段训练关系图，以及 FAST 动作编码学习动画。
- 策略后训练与推理：区分已知示范下的训练和无示范答案时的动作生成；展示知识隔离的信息与学习反馈路径。
- 讨论：四层实验室能力定位。
- 研究局限：真实验证、自主性、协作与失败解释三类边界。

新增动画支持播放、暂停、进度拖动和按步骤查看。页面支持侧栏导航与移动端布局；宽图示可在图框内滚动。默认尊重系统的减少动态效果设置。

## 内容边界与素材

图示均为项目代码绘制的教学示意，不是真实机器人实验录像，也不表示真实系统的完整控制或物理仿真。专家与科学家场景展示能力定义，论文未证明 LabVLA 已达到这两个层级。

本项目按教学展示范围省略公式、论文原图与实验数据图表；讨论保留论文明确提出的验证范围和局限。流程图中的箭头表示信息或操作关系。

全部机械臂、器具与动画由 Canvas 绘制，不使用第三方图片、视频、外部字体或论文原图。交互页面截图由本项目生成，仅用于提交预览。
