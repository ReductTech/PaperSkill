# 教程质量检查指南

本指南用于帮助使用者和审核者判断交互式论文教程是否准确、清楚并且可用，不设置分数、通过线、修改数量或现场展示要求。

## 1. 论文内容与信息传达

- 准确说明研究问题、核心动机、方法贡献、适用条件和局限；
- 公式、模型结构、实验协议、指标方向、数字和结论与原论文一致；
- 重要结论能够追溯到论文中的章节、公式、表格或图；
- 不把相关性写成因果关系，不把特定实验条件扩展为普遍结论；
- 对论文未验证的部署效果、性能或泛化能力保持明确边界。

## 2. 教学组织与讲解

- 内容从问题、直觉和必要背景逐步进入方法、实验与局限；
- 首次接触该领域的读者能够理解术语、变量和模块之间的关系；
- 类比与原方法的对应关系明确，不以过度简化造成误解；
- 章节之间有清楚的承接，避免重复、跳跃或只复述论文原文；
- 页面中的提示说明用户当前可以执行什么操作，以及操作结果代表什么。

## 3. 可视化与交互

- 主要交互直接表达论文机制，而不是仅用于装饰；
- 用户操作后有即时、可辨认且正确的状态变化；
- 图例、颜色、标签和坐标含义一致，图表不会暗示错误结论；
- 动画、Canvas、SVG、图片和表格在桌面端与手机端均完整显示；
- 键盘操作、焦点状态和基本可访问性不会阻碍使用。

## 4. 完成度与工程质量

- 项目能够安装、启动和构建，主要页面及交互可正常使用；
- 不存在横向溢出、遮挡、空白画布、失效链接或资源加载错误；
- 教程覆盖论文的核心方法、主要实验、适用条件和已知局限；
- 论文、图片和外部素材来源可追溯，并确认允许公开使用；
- 仓库中不包含论文 PDF、密钥、个人隐私、本地绝对路径、`node_modules/` 或 `dist/`。

## 5. 人工核验结果

人工核验完成时，使用者应能够确认：

- 网页对论文核心内容的表述准确；
- 主要交互的含义和反馈正确；
- 桌面端和手机端均可正常浏览；
- 已知问题已修复，或已在提交说明中明确列为待审核事项。

人工核验不要求固定数量的修改，也不需要单独制作修改说明或现场展示材料。
