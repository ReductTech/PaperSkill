# 公共仓库提交说明

本文件只说明如何把已经完成人工核验的教程贡献到 PaperSkill 公共仓库。只在本地使用生成网页时，不需要导入仓库或创建 Pull Request。

## 1. 仓库接收的内容

公共仓库接收能够安装、运行和构建的完整 React + TypeScript 教程项目，统一放入：

```text
html_output/<paper-name>/
```

`paperName` 是论文标题全称的小写下划线形式，例如 `attention_is_all_you_need`，并作为目录名与 `paper.json` 中的唯一标识。

项目应包含 `package.json`、依赖锁文件、`src/`、`public/`、`paper.json` 和项目 `README.md`，不得只提交构建后的单个 HTML 文件。分支、导入命令和本地检查见 [PARTICIPATING.md](PARTICIPATING.md)。

## 2. 不进入公共仓库的内容

以下内容必须保留在仓库外：

- 论文 PDF 或其他没有公开分发权限的全文；
- 密钥、令牌、账号信息和个人隐私；
- `node_modules/`、`dist/`、本地缓存和临时文件；
- 本地绝对路径；
- 来源不明或未获授权的图片、视频、字体和其他素材。

公开论文链接可以写入 `paper.json` 和项目 `README.md`。使用论文图片或其他外部素材时，必须注明来源并确认允许公开使用。

## 3. Pull Request 内容

Pull Request 应包含：

- 论文名称、教程目录和提交分支；
- 本次新增或更新内容的简要说明；
- 提交前使用的网页预览地址或预览方式，以及使用者确认结论；
- 关键页面截图和主要交互说明；
- Agent 自动检查结果；
- 仍需审核者重点确认的问题。

## 4. 提交检查

- [ ] Agent 已针对最终待提交源码自动完成仓库校验、目录生成、PR 范围、单篇构建、差异格式和禁止提交文件检查，且全部通过；
- [ ] 已由使用者对照原论文核验网页事实、公式、模型结构、实验数字、结论和局限；
- [ ] 已用最终源码提供可运行的网页预览，并由使用者确认桌面端和手机端显示、资源加载与主要交互正常；
- [ ] Pull Request 原则上只包含目标教程目录，不包含自动生成的 `catalog/papers.json`；
- [ ] 论文链接和外部素材来源可追溯，且允许公开使用；
- [ ] 仓库中不含论文 PDF、隐私、密钥、本地路径或生成缓存。

论文内容准确性应按照菜单功能 3 的提示，由使用者对照所选论文完成人工核验。
