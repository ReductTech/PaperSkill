# 功能三：人工校验网页准确性

**定位：本功能要求使用者对照原论文人工核验网页内容。Agent 可以整理证据和指出疑点，但不得代替使用者确认信息正确。**

开始核验前，Agent 必须先提示使用者：

> 请重点检查网页是否正确表述了您所选论文的内容，尤其注意研究问题、方法、公式、实验数据、结论和局限是否与原论文一致。发现任何不准确、遗漏或容易误解的内容，请指出后再继续后续步骤。

人工核验至少覆盖：

- 研究问题、核心动机、方法贡献与适用范围；
- 公式、符号、模型结构和关键算法步骤；
- 实验设置、数据集、评价指标、实验数字和对比结论；
- 论文结论、局限、引用、图表说明和专业术语。

Agent 应根据原论文和实际网页，向使用者列出核验结果与候选问题。每项包含：

- 初版问题和位置；
- 论文原文、公式、实验数据或测试结果依据；
- 建议修改内容；
- 修改原因和预期效果；
- 所属类别。

本流程不再要求固定数量的修改。没有发现错误时，也必须记录人工核验范围和结论；发现不准确内容时，应先修正并重新核验，再进入导入和提交阶段。

完成前，Agent 必须向使用者展示核验结论，并由使用者明确确认网页信息与论文一致，或指出仍需修正的内容。
