# 功能二：调用 paper-skill 生成网页

1. 让使用者确认论文；
2. 在仓库外创建独立工作目录，不把论文或临时文件写入 `html_output/`；
3. 调用已安装的 `paper-skill`；
4. 让 Skill 连续完成论文读取、教学规划、React + TypeScript 项目生成和结构验证；
5. 获得唯一的 `<paper-short-name>_output/` 初版项目；

生成完成后，执行依赖安装、构建与本地预览：

```powershell
npm install
npm run build
npm run dev
```

本功能只完成初版生成和基础工程检查，不得代替功能 3 的论文准确性人工核验。完成后，Agent 应报告生成结果、项目路径、构建状态、本地预览地址，以及桌面端和手机端的基础页面检查结果。

报告后必须继续显示以下引导，并暂停等待使用者选择：

```text
请选择下一项功能：

1. 自动准备环境
2. 调用 `paper-skill` 生成网页
3. 人工校验网页准确性
4. 导入主仓库
5. 准备提交 PR
```

不得只报告“功能 2 已完成”，也不得未经使用者选择就进入功能 3。使用者回复 `3` 或明确要求“人工校验网页准确性”后，才读取并执行 `03-review-suggest.md`。
